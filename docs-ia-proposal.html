A docs sidebar you can follow

Today's docs are one flat list filed by the old site's categories. This proposal regroups every page around what a new user does, in order: get ready, install a distro, open the desktop, use it. Look-up material (troubleshooting, reference) comes after that, and the pre-2.0 material sits in a collapsed archive. It's now implemented on the docs branch, with every old URL redirected; the questions at the end are still open.
