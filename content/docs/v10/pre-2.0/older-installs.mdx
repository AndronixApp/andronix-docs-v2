<Callout type="info">**Upgrading from an older Modded OS?** If you installed a Modded OS with the old Andronix app (8.x or earlier), see [Upgrading from an older Modded OS](/v10/modded-os/upgrade): back up your files, uninstall the old version, then install the new one.</Callout>

Andronix 2.0 brings a new installer for the free distros. If you installed a distro before Andronix 2.0, this page explains what happens to that install and how to move to the new one.

<Callout type="info">**Nothing changes for your existing install.** Andronix 2.0 never modifies or deletes a distro installed by the old one, unless you ask it to.</Callout>

## How to tell which installer you used

Run this in Termux:

```bash copy
andronix list
```

Distros from the pre-2.0 installer are listed as **from the old installer**, with their folder, for example `~/debian-fs`. If the command isn't found, you haven't used Andronix 2.0 yet, and everything you have is from the old one.

Other signs of an old install:

- It logs you in as `root` (`root@localhost`). New installs log you in as your own user.
- Its files are in a folder like `~/debian-fs` or `~/ubuntu-fs` in Termux. New installs live in `~/.andronix/distros/`.

## Outdated versions

The pre-2.0 installer set up versions that are now out of date. Andronix 2.0 replaces them:

| Before 2.0 | Andronix 2.0 |
|---|---|
| Ubuntu 18.04, Ubuntu 20.04 | Ubuntu 24.04 LTS |
| Ubuntu 22.04 | Ubuntu 26.04 LTS |
| Older Debian, Kali, Fedora, Arch, Manjaro, Alpine and Void | The current versions, see [Supported Distros](/v10/reference/distros) |
| Window managers (Awesome, i3, Openbox) | Retired. Pick a [desktop environment](/v10/reference/desktops) instead. |
| LXDE and other desktops | XFCE, LXQt, MATE or KDE Plasma |

Your old install keeps working as it is, but it won't get these new versions.

## Installing the new version next to the old one

You can install the same distro with Andronix 2.0 while you still have the old one. The new install goes into its own folder, and your old install is left alone.

- The new install uses the usual start script name, for example `start-debian.sh`.
- If you already had a start script with that name from the pre-2.0 installer, it's kept under a different name so you can still start your old install. Run `ls ~/start-*` in Termux to see your start scripts.

## Moving your files

The new install starts fresh. To bring files across:

1. In the old distro, copy what you want to keep to `/sdcard`, for example `cp -r ~/Projects /sdcard/`.
2. Install the new version from the app.
3. In the new distro, copy the files back from `/sdcard`.

Programs you installed in the old distro need to be installed again in the new one.

## Removing an old install

When you no longer need the old install, remove it from Termux:

```bash copy
andronix remove debian --legacy
```

Replace `debian` with the name of your distro. `--legacy` removes the old install's folder, its start script and its `~/<distro>-binds` folder. If the same distro is also installed with Andronix 2.0, that's removed too, so only use this when you want both gone.

You can also keep using the app's **Uninstall** button, as before. See [Uninstalling a Distro](/v10/install/uninstall).

**The old uninstall scripts still work**, if you'd rather use them. Each removes one old free distro's folders from Termux's home. For example, for Ubuntu:

```bash copy
cd ~ && curl -fsSL https://raw.githubusercontent.com/AndronixApp/AndronixOrigin/master/Uninstall/Ubuntu/UNI-ubuntu.sh -o UNI-ubuntu.sh && bash UNI-ubuntu.sh
```

The others are in the same place, one folder per distro: `Alpine/UNI-alpine.sh`, `Arch/UNI-arch.sh`, `Debian/UNI-debian.sh`, `Fedora/UNI-fedora.sh`, `Kali/UNI-kali.sh`, `Manjaro/UNI-manjaro.sh`, `Parrot/UNI-parrot.sh`, `Ubuntu19/UNI-ubuntu19.sh`, `Ubuntu20/UNI-ubuntu20.sh`, `Ubuntu22/UNI-ubuntu22.sh` and `Void/UNI-void.sh`. Run them in Termux's home folder (`cd ~` first). They leave Andronix 2.0's distros in `~/.andronix` alone, but they also delete the start script (for example `start-debian.sh`), which Andronix 2.0 uses too: if you have the same distro from 2.0, run `andronix install debian` afterwards to write it again. For an old **Modded OS**, see [Upgrading from an older Modded OS](/v10/modded-os/upgrade#3-uninstall-the-old-version).
