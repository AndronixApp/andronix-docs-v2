This page covers problems while installing a free distro, and just after. For desktop problems, see [The desktop is black, slow or closes](/v10/troubleshooting/desktop); for Termux errors, see [Termux errors](/v10/troubleshooting/termux). If yours isn't here, see [Still stuck?](#still-stuck) at the bottom.

## The install stopped halfway

Android sometimes stops long-running apps in the background, the connection drops, or Termux gets closed by accident. None of that ruins your install.

**Fix:** paste and run the **same install command** again. The installer remembers which steps finished and picks up where it stopped. You'll see those steps marked as done or skipped.

<Callout type="info">While it installs, Andronix keeps your phone from putting Termux to sleep. If Android asks whether Termux can keep running in the background, tap **Allow**.</Callout>

## Process completed (signal 9) - press Enter

This error comes from Android's **phantom process killer** (Android 12 and newer), which kills apps that start too many processes. It can hit during an install or while you use the desktop.

**Fix:** turn off the phantom process killer by following [Process completed (signal 9)](/v10/troubleshooting/signal-9). Then run the install command again; it continues where it stopped.

Also disable battery optimization for Termux in your phone's settings.

## Not enough storage

The installer checks your free space before it starts, and warns you if it looks too low. Roughly how much a distro takes once installed:

| Install | Space used |
|---|---|
| Command line only | 250 to 400 MB |
| XFCE or LXQt desktop | 0.8 to 1.6 GB |
| MATE desktop | 1.5 to 1.9 GB |
| KDE Plasma desktop | about 2.5 GB |

Leave some extra room for the download while it unpacks. If you're short on space, free some up, pick a smaller desktop, or use the command line only. Use `andronix list` to see what's installed, and [remove](/v10/install/uninstall) distros you don't use.

<Callout type="info">Distros can only be installed on your phone's internal storage, not on an SD card. See [Limitations](/v10/reference/limitations#hardware-limitations).</Callout>

## Download errors

- **The download failed or timed out:** check your connection and run the same command again. The download resumes instead of starting over.
- **The installer says your network hit the limit:** the fallback download source limits how many downloads come from one network. Wait a while and try again, or switch between Wi-Fi and mobile data.

## The installer warns about an old kernel

Some older phones (for example Android 8 or 9 phones on a 4.4 kernel) run a Linux kernel older than 4.8. Desktops install and work on many of them, but on some the desktop stays black. The command line always works.

The app (10.0.3 and newer) shows a notice when you pick a desktop, and `andronix` warns before a desktop install, `andronix desktop` and `vncserver-start`. From installer 2.0.5 the warning reads:

```text
This phone's Linux kernel (4.4.x) is older than 4.8. Desktops work on many such phones but may stay black. If yours does: andronix desktop --legacy-drawing, or try VNC (vncserver-start). The command line always works.
```

Installer 2.0.4 still says the desktop stays black and suggests `--de none`. You can install a desktop anyway.

**If the desktop stays black:**

1. **Try legacy drawing.** In Termux, stop the desktop and open it again with `--legacy-drawing` (installer 2.0.4 or newer). Andronix remembers it for the next start.

   ```bash copy
   andronix desktop stop
   andronix desktop --legacy-drawing
   ```

2. **Try VNC.** Inside the distro, run `vncserver-start`, then connect a VNC viewer. See [Other ways to connect (VNC)](/v10/reference/vnc).
3. **Use the command line.** Everything except the desktop works: command-line software, dev packs and servers. To skip the desktop, install with `--de none` (for example `andronix install debian --de none`) or pick **CLI Only** in the app.

**Check your kernel:** run `uname -r` in Termux. `4.4.x` or `4.9.x`? A `4.9` kernel is fine; only versions below 4.8 are affected.

**Modded OS needs kernel 4.8 or newer.** Below that, the app shows "Modded OS needs a newer kernel" and doesn't offer the editions.

Tell us how it went: [Report a problem](/v10/troubleshooting/report-a-problem) or ask on [Discord](https://chat.andronix.app), with the output of `uname -r`.

## Your phone isn't supported by a distro

In its first step, the installer checks your phone's CPU. If a distro isn't available for it (for example, Fedora and Manjaro need a 64-bit phone), it tells you. Pick another distro from [Supported Distros](/v10/reference/distros).

## I forgot my password

In Termux, open a root shell in the distro and set a new password for your user:

```bash copy
andronix start debian --root
passwd alex
```

Replace `debian` with your distro and `alex` with your username. To reset the desktop (VNC) password, see [Changing the desktop password](/v10/reference/vnc#changing-the-desktop-password).

## sudo prints "unable to send audit message"

`sudo: unable to send audit message: Operation not permitted` is harmless. Your command still runs as root.

## Still stuck?

- Every install, remove, backup and restore writes a log to `~/.andronix/logs/` in Termux. Include the latest one when you ask for help.
- With installer 2.0.1 or newer, also include the output of `andronix doctor`: it shows your phone's details and the fixes Andronix applies. See [andronix doctor](/v10/reference/andronix-command#checking-your-phone-andronix-doctor).
- [Report a problem](/v10/troubleshooting/report-a-problem): right after a failed command, run `andronix report` in Termux (installer 2.0.2+), or use the form in the Andronix app. Either attaches your phone's details and gives you a report ID.
- Ask on our [Discord](https://chat.andronix.app), or email [support@andronix.app](mailto:support@andronix.app).
- Check the [FAQ](/v10/troubleshooting/faq).
