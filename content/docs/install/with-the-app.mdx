Installing your favorite Linux distro with Andronix only takes a few minutes. This guide walks you through the whole process: picking a distro, choosing an interface, running the install command in Termux, creating your user, and starting your new system.

<Callout type="info">These instructions need the **Andronix app 10.0 or newer (Andronix 2.0)**. Don't want to use the app? See [Install without the app](/install/without-the-app).</Callout>
<Callout type="info">This is **not** a guide for installing a **Modded OS**. For that, see [Installing Modded OS](/modded-os/modded-os-installation).</Callout>

## 2. UI Selection ⭐️

### Select
Tap the distro you'd like to install.

<Callout type="warning">Not sure which one to pick? We recommend starting with **Ubuntu**.</Callout>

### Select the UI
Next, choose the kind of interface you want. This decides how you'll interact with your distro once it's running.

<Imagera src="/images/install_new/install_gui_selection.jpg"/>

<Callout type="info">A Graphical User Interface (GUI) is the visual interface, with windows, icons and a mouse pointer, that you use to get things done in your Linux distribution.</Callout>

<Callout type="info">A Command Line Interface (CLI) is the text-based interface where you type commands to perform tasks in your Linux distribution.</Callout>

#### **Desktop Environment** <Badge>GUI</Badge>
Choose a Desktop Environment if you want to use your mouse as well as your keyboard, or if you have little or no experience with Linux. [Learn more about Desktop Environments](/reference/desktops).

#### **Command Line Interface** <Badge>CLI</Badge>
Choose the **Command Line Interface** if you don't need a graphical interface. You'll get a terminal, which is all you need if you know your way around Linux. You can add a desktop later with [`andronix install`](/reference/andronix-command#installing).

<Callout type="warning">**Window managers have been retired.** Andronix 2.0 offers desktop environments (XFCE, LXQt, MATE, and KDE Plasma on some distros) and the command line only. If your version of the app still shows a Window Manager option, pick a Desktop Environment instead. [Read more](/pre-2.0/window-managers).</Callout>

<Callout type="info">If you can't decide, we always recommend going with a Desktop Environment.</Callout>

### Continue
Follow the instructions below that match the option you picked.

#### Desktop Environment

Select the Desktop Environment (DE) you'd like to install: **XFCE**, **LXQt**, **MATE**, or **KDE Plasma** (Debian, Ubuntu 26.04 and Kali only). If you want to compare them first, read the [Desktop Environments](/reference/desktops) page. If you're not sure, pick **XFCE**.

## 3. Termux Execution 💻

This is where the actual installation of your Linux distribution happens.

<Callout type="info">The Andronix app has automatically copied an install command to your clipboard.</Callout>

<Imagera src="/images/install_new/install_termux_exec.jpg"/>

### Execute
You'll run this command in Termux to download and set up the distro.

<Callout type="warning">Before you continue, make sure you're using a compatible version of Termux. If you haven't already, follow the [Migrating Termux to F-Droid](/start-here/install-termux) guide.</Callout>

### Paste
Open the Termux app, **long press to paste the copied command, then press Enter to run it**.

<Imagera src="/images/termux_pkg_up.png"/>

### Wait
The command sets up the `andronix` installer and runs it. You'll see a list of steps, each ticked off with a ✓ as it finishes, with a progress bar for the long ones:

```text
✓ Installing proot          (only if Termux doesn't have it yet)
✓ Checking your phone
✓ Finding the best download
✓ Downloading Debian 13
✓ Unpacking files
✓ Setting up Debian 13
✓ Refreshing package lists
✓ Updating Debian 13
✓ Installing XFCE desktop · 250 packages
✓ Installing Firefox
✓ Setting up the desktop
✓ Writing start-debian.sh
```

A desktop install usually takes a few minutes, depending on your phone and connection. Keep Termux open until it finishes.

<Callout type="warning">Android may ask whether Termux can keep running in the background. Tap **Allow**, and disable battery optimization for Termux, so Android doesn't stop the install.</Callout>
<Callout type="info">If the install stops for any reason, paste and run the **same command** again. It continues where it left off. See [Troubleshooting installs](/troubleshooting/install) if it keeps failing.</Callout>

### Create your user
When the install finishes, it asks you to set up your user:

1. **Username**: lower-case letters and numbers, for example `alex`.
2. **Password**: used to log in and for `sudo`.
3. **Desktop (VNC) password**: 6 to 8 characters. If your password is 6 to 8 characters long, you can reuse it.

<Callout type="info">Free distros no longer log you in as `root`. Your user can run any command as root with `sudo`, for example `sudo apt install nano`. On Manjaro, where `sudo` doesn't work yet, use `andronix start manjaro --root` from Termux instead.</Callout>

When it's done, the installer takes you straight into your new distro.

### Update the Andronix app
Back in Andronix, tap the **Command Executed** button at the bottom of the screen. This tells the app the command has been run.

### Finish the Process
Once the script has finished successfully, tap the **Execution Finished** button at the bottom.

<Imagera src="/images/install_new/install_script_exec.jpg"/>

## 4. Starting Distribution ⚡️

<Callout type="info">If you're already in the distro shell (you see your username, like `alex@localhost`, in Termux), **skip the next section.**</Callout>

### Start the Distro
Next time, start the distro by running the command for your distro in Termux:

| Distro | Command |
|---|---|
| Debian 13 | `./start-debian.sh` |
| Ubuntu 26.04 LTS (the app's **Ubuntu 22** button) | `./start-ubuntu26.sh` or `./start-ubuntu22.sh` |
| Ubuntu 24.04 LTS (the app's **Ubuntu 18** and **Ubuntu 20** buttons) | `./start-ubuntu.sh` or `./start-ubuntu20.sh` |
| Kali Linux | `./start-kali.sh` |
| Fedora 44 | `./start-fedora.sh` |
| Arch Linux | `./start-arch.sh` |
| Manjaro ARM | `./start-manjaro.sh` |
| Alpine 3.24 | `./start-alpine.sh` |
| Void Linux | `./start-void.sh` |

You can also use `andronix start <distro>`, for example `andronix start debian`. See [Supported Distros](/reference/distros) for details on each one.

### Verify
If you see your username followed by `@localhost` in the shell, your distro is up and running. Type `exit` to go back to Termux.

## 5. Start the desktop 📺

If you chose a Desktop Environment, open it next.

### VNC Start

The **Start VNC server** page should now be open in the Andronix app.

<Imagera src="/images/install_new/install_start_vnc.jpg" />

### VNC Server

There are two ways to open your desktop; Step 3 covers both:

- **[Termux:X11](/desktop/termux-x11)** shows it full screen on the phone. In Termux, run `andronix desktop`.
- **[VNC](/desktop/vnc)** shows it in a VNC viewer app, on the phone or another device. Inside the distro, run `vncserver-start`.

<Callout type="warning">Keep the Termux session open while you use the desktop. Closing it, or typing `exit`, stops the desktop too.</Callout>

![Debian 13 with XFCE, seen in a VNC viewer](/images/new-installer/debian-xfce-desktop.png)
