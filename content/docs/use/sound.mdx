This page shows how to get sound working in your distro, so you can listen to music from Spotify (or anything else) through your phone's speakers while you code. We use PulseAudio to route sound out of the PRoot container to your phone's speakers.

<Callout type="info">The Classic Modded OS editions have sound output through the phone's speakers enabled out of the box.</Callout>

## Sound on a new install

Distros from Andronix 2.0 are already set up to send their sound to Termux. Termux only needs PulseAudio installed.

<Steps>
<Step>

### Close Distro

If your distro is running, stop the desktop with `vncserver-stop` and close the distro by running `exit`. _Skip this step if your distro isn't running._

</Step>

<Step>

### Install PulseAudio

Run the following command in **Termux (not inside Linux)**:

```bash copy
pkg install pulseaudio
```

</Step>

<Step>

### Start the distro

Start your distro as usual, for example with `./start-debian.sh`. Andronix starts PulseAudio for you each time, so there's nothing else to run.

</Step>
</Steps>

## Sound on an old install

<Callout type="warning">These steps are for distros installed with the **pre-2.0 installer**.</Callout>

Follow these steps in order to enable sound output:

<Steps>
<Step>

### Close Distro

If your distro is running, close it by running `exit` inside Termux. _Skip this step if your distro isn't running._

```bash copy
exit
```

</Step>

<Step>

### Run Commands

Run the following command in **Termux (not inside Linux)**:

```bash copy
pkg install wget && wget https://andronixos.sfo2.cdn.digitaloceanspaces.com/OS-Files/setup-audio.sh && chmod +x setup-audio.sh && ./setup-audio.sh
```

</Step>

<Step>

### Start PulseAudio Server

Start the PulseAudio server:

```bash copy
pulseaudio --start
```

</Step>
</Steps>
