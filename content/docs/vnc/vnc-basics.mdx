VNC lets you see and use your distro's graphical desktop from a VNC client app. This page shows you how to start and stop the VNC server, connect to it, tweak its resolution and picture quality, and access it from other devices on your network.

## Operating the VNC Server

Let's learn how to operate the VNC server, including starting, stopping and debugging it.

<Callout type="info">Make sure you have started your distro and are in the distro shell, i.e. you see `root@localhost` in Termux.</Callout>

### Starting a VNC server

<Steps>
<Step>

### Start VNC Server

If you are on the VNC server page in Andronix, the app has already copied the necessary command to your clipboard. Just paste it in Termux (in the distro shell, _[root@localhost]_) and run it.

```bash copy
vncserver-start
```

<Callout type="warning">Always remember to **stop the VNC server** by running `vncserver-stop` before exiting the distro.</Callout>

### Stopping a VNC server

Stop the VNC server whenever you're done using your distro or are about to exit it. To do so, run the following command in the distro shell:

```bash copy
vncserver-stop
```

The terminal will then ask you for a port number. Enter **1** and press **Enter**.

## VNC Settings

<Callout type="info">These instructions assume that you have started your distro and are inside the distro shell (not the Termux shell).</Callout>

### Setting a desired resolution

To set your preferred resolution, open the VNC start script by running:

```bash copy
nano /usr/local/bin/vncserver-start
```

Then change the last line of the file to:

```bash copy
vncserver -name remote-desktop -geometry 1920x1080 :1
```

<Callout type="info">You can replace 1920x1080 with your desired resolution.</Callout>

Save the file by pressing `ctrl + x`, then `y`, and finally `Enter`.

### How to change resolution permanently in Modded OS /Ubuntu 19

To change the resolution permanently, run the following command in the distro's shell:

```bash copy
nano /usr/local/bin/vnc
```

Then replace the second line with:

```bash copy
LD_PRELOAD=/lib/aarch64-linux-gnu/libgcc_s.so.1 vncserver -localhost no -depth 24 -name remote-desktop -geometry 1920x1080 :$PORT
```

<Callout type="info">You can replace 1920x1080 with your desired resolution. Then restart (or start) the VNC server.</Callout>

When you're done, press `Ctrl+X`, type `Y` and press `Enter`. The next time you start the VNC server, choose the first option, **Start vnc-server with autodetect/dynamic resolution**.

### How to change the picture quality in VNC

If you're using bVNC, you don't need to change anything; it adjusts the quality automatically.

If you're using RealVNC Viewer, connect to the VNC server and tap the _(i)_ button at the top. Then change
**Picture Quality** to **High**, or to whatever quality you prefer.

## VNC on other devices

<Callout type="info">You can access the distro running on your phone from any other device on your network.</Callout>

First, make sure both devices are on the same network. If you don't have access to Wi-Fi, turn on the hotspot on the
device running Linux and connect the other device to it. Once both devices are on the same network, run the following
command inside the distro's shell:

```bash copy
nano /usr/local/bin/vncserver-start
```

Now change the last line to:

```bash copy
vncserver -name remote-desktop -geometry 1920x1080 -localhost no :1
```

<Callout type="warning">If you're using an Arch-based distro such as Manjaro, or Arch Linux itself, use the following line instead:</Callout>

```bash copy
vncserver -name remote-desktop -geometry 1920x1080 -localhost :1
```

When you're done, open a new Termux session (swipe in from the left edge to open the sidebar for more options) and
type:

```
ip a
```

Copy the **WLAN IP** address (e.g. _192.168.xx.xx_). On the other device, connect to this IP address with port
number 1 (e.g. _192.168.xx.xx:1_).
