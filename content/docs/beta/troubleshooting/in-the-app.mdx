## Known limits in the beta

- **arm64 and Android 8 or newer only.** Other devices use Termux. See [Requirements](/beta/start-here/requirements).
- **Sound plays, but there's no microphone** yet.
- **The first install takes 5 to 30 minutes.** It keeps going in the background with the **Linux is running** notification.
- **One distro runs at a time.**
- **Android 11 and newer:** Linux can't see files that other apps put in Download/Andronix. Use **Import** or **Send to Linux**. See [Android files in Linux](/beta/use/android-files).
- **Firefox says its security sandbox is disabled.** That's needed for Linux to run inside the app; Firefox can still only reach what Android lets the app reach.
- **GPU acceleration is experimental,** and can be slower on fast devices. See [GPU acceleration](/beta/use/gpu).
- **Safe mode can remove window title bars.** See [Black screen and safe mode](/beta/troubleshooting/black-screen).
- **Home-screen shortcuts need a launcher that supports them.** Most do; we tested Pixel and Samsung. See [Linux apps on your home screen](/beta/use/shortcuts).

## Common problems

| Problem | What to do |
|---|---|
| **In the app** is dimmed | The app says why. See [How the app checks](/beta/start-here/requirements#how-the-app-checks). |
| The install stopped | Tap **Try again**. If it says "Not enough space", free up a few GB first. |
| The desktop stays black | Andronix fixes it by itself. See [Black screen and safe mode](/beta/troubleshooting/black-screen). |
| A Linux command says to run it in Termux | Commands that manage installs (install, start, remove, update, backup) are done with the app's buttons here. Type `exit` to leave the distro first. |

## Report a problem

The best way to tell us is **Report a problem** in the app: see [Report a problem](/beta/troubleshooting/report-a-problem). For distros in the app, the report can attach your last failed install and its log ("Attach my last install"), with personal details removed. It shows exactly what it will send first.

In this beta, the **Report a problem** buttons on the install-failed screen and on the black-screen and GPU sheets open an email to us instead, with the distro filled in.

You can also tell us in **#standalone-beta**, the beta channel on our <BetaLink to="discord">Discord</BetaLink>: other testers and the team read it.
