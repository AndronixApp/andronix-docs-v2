This page collects the questions we get asked most often about Andronix, along with their fixes. If your problem isn't listed here, see [Still need help?](#still-need-help) at the bottom.

### 1. How do I upgrade or uninstall my old Modded OS?

Installing the new version doesn't remove or update a Modded OS from the old Andronix app (8.x or earlier). Back up your files, uninstall the old version (for example `andronix remove legacy-ubuntu-kde --legacy`, or by hand), then install the new one from the app. Step by step: [Upgrading from an older Modded OS](/beta/modded-os/upgrade).

### 2. Process completed (signal 9) - press Enter

We're sorry you're running into this. The error is caused by Android's phantom process killer. Read
[this page of the documentation](/beta/troubleshooting/signal-9) to fix it. You can also follow the video guide (https://youtu.be/mjXSh3yq-I0) to fix it on your device.

___

### 3. Getting this error whenever I try to install any OS

<Imagera src="/images/distro_error.jpg" alt="Termux pkg update failing with 403 Forbidden errors from the old Bintray package servers"/>

**Ans.** You probably have the old Play Store build of Termux from 2020, whose package servers are gone. Replace it with a current Termux; see [Install Termux](/beta/start-here/install-termux).

___

### 4. Kali Linux errors out during installation

**Ans.** Andronix 2.0 installs Kali Linux rolling again. Install it from the app as usual. If it still fails, see [The install fails or stops](/beta/troubleshooting/install).

___

### 5. Modded Manjaro gives repository errors whenever I try to install or update any package

**Ans.** Follow [this guide](https://youtu.be/SAGt39yYV0Y), and you'll be good to go.

___

### 6. AltGr not working on VNC

<Imagera src="/images/faq/altgr.png" alt="bVNC menu option that fixes the AltGr key"/>

**Ans.** Use [bVNC](https://play.google.com/store/apps/details?id=com.iiordanov.freebVNC) instead of [RealVNC](https://play.google.com/store/apps/details?id=com.realvnc.viewer.android) and select the highlighted option from the top menu. If that doesn't work either, try [Android VNC](https://play.google.com/store/apps/details?id=android.androidVNC&hl).

___

### 7. VNC can't open – usage: vncserver -display- error

<Imagera src="/images/faq/vncError.png" alt="vncserver usage error shown in the Manjaro shell" width="400"/>

**Ans.** Most users run into this error while using Modded Manjaro. To fix it, run this inside the Manjaro shell:

```bash copy
sudo pacman -S wget tar sed --noconfirm && wget https://raw.githubusercontent.com/AndronixApp/AndronixOrigin/master/Pacman/tigervnc-fix.sh && sudo bash tigervnc-fix.sh
```

___

### 8. Ubuntu 20.04: Firefox shows "Gah. Your tab just crashed"

This applies to Ubuntu 20.04 from the pre-2.0 installer. Here's an easy fix for this error:

1. Enter about:config in the address bar.
2. Click "Accept the risk and continue".
3. Click "Show all".
4. Search for sandbox.
5. Change the first two values to false, and change security.sandbox.content.level to 1, exactly as in this picture:
<Imagera src="/images/faq/firefox.png" alt="Firefox about:config sandbox settings changed to fix tab crashes" height={500}/>
6. Restart Firefox.

___

### 9. Why does my new distro ask for a username instead of logging in as root?

**Ans.** Distros from Andronix 2.0 create a normal user for you, like a regular Linux PC. Use `sudo` for commands that need root (on Manjaro, where `sudo` doesn't work yet, use a root shell instead). If you really need a root shell, run `andronix start <distro> --root` in Termux. See [First login](/beta/reference/andronix-command#first-login).

___

### 10. Where did the window managers go?

**Ans.** Window managers (Awesome, i3 and Openbox) have been retired from the free installer. Pick a desktop environment instead: XFCE, LXQt, MATE or KDE Plasma. Existing installs keep working. See [Window Managers](/beta/pre-2.0/window-managers).

___

### 11. Can I still use my old distro?

**Ans.** Yes. Distros installed with the pre-2.0 installer are left untouched and start with the same command as before. See [Installs from before Andronix 2.0](/beta/pre-2.0/older-installs).

### 12. How much does Modded OS cost, and do I pay again for my old Modded OS?

The Modded Pass is $6.99. Premium owners get 30% off the Modded Pass, and owners of a Modded 2.0 edition 40% off. Prices vary by region, and discounts are applied to your local price; Google Play shows your final price before you buy. See [Prices](/beta/modded-os/modded-os#prices). If you bought a Modded OS before Andronix 2.0, those Classic editions stay yours for free under **Archived — yours to keep** in the app. They don't lower the price of Modded 2.0.
