This page shows how to resolve the "CANNOT LINK EXECUTABLE" error for `wget`, `curl` and other utilities in Termux. Work through the solutions in order, starting with the most common fix.

<Callout type="error">
If you see **CANNOT LINK EXECUTABLE "wget": library "libssl.so.3"** or a similar error for `curl` and other commands, follow the solutions below.
</Callout>

## The Problem

This error occurs when Termux utilities like `wget` or `curl` cannot find or link to the required OpenSSL library (`libssl.so.3`). This typically happens because of:

- Outdated or corrupted package repositories
- Missing OpenSSL dependencies
- Repository mirror connection issues

## Solutions

Try these solutions in order. If one doesn't work, move on to the next.

### Solution 1: Change Repository Mirror

The most common fix is to switch to a more reliable repository mirror.

<Steps>
<Step>

### Open the repository selection tool

```bash copy
termux-change-repo
```

</Step>

<Step>

### Select "Main repository"

Use the arrow keys to navigate and press Enter to select.

</Step>

<Step>

### Choose "Mirror by BFSU"

Select the BFSU (Beijing Foreign Studies University) mirror from the list.

</Step>

<Step>

### Confirm and apply

Press OK to apply the changes.

</Step>

<Step>

### Restart Termux

Close the Termux app completely and open it again.

</Step>

<Step>

### Test the fix

Run your command again:

```bash copy
wget --version
```

or

```bash copy
curl --version
```

</Step>
</Steps>

### Solution 2: Update and Upgrade Packages

If changing the repository doesn't resolve the issue, try updating all packages.

<Steps>
<Step>

### Update package lists

```bash copy
apt-get update
```

</Step>

<Step>

### Upgrade installed packages

```bash copy
apt-get upgrade
```

</Step>

<Step>

### Test the fix

Run your command again to check that it works.

</Step>
</Steps>

### Solution 3: Reinstall OpenSSL

If neither of the solutions above works, the OpenSSL library may need to be reinstalled.

<Steps>
<Step>

### Install OpenSSL

```bash copy
apt install openssl
```

This installs (or reinstalls) the required `libssl.so.3` library.

</Step>

<Step>

### Verify installation

Check whether the error is resolved:

```bash copy
wget --version
curl --version
```

</Step>
</Steps>

## Additional Tips

<Callout type="info">
If the issue persists after trying all the solutions:
- Make sure you have a stable internet connection
- Try a different repository mirror if BFSU doesn't work
- Consider reinstalling Termux from F-Droid (recommended) instead of the Play Store
</Callout>
