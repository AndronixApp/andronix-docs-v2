Andronix runs a full Linux distro, like Debian, Ubuntu or Fedora, on your Android phone or tablet, with a real desktop and no root. Since Andronix 10.1, the app runs Linux **itself**: pick a distro, start the install, and the desktop opens in the app, with sound. Nothing else to install and no commands. New here? Follow the four steps below, in order.
