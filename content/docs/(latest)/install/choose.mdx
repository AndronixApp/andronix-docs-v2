Andronix offers nine free distros and four desktops. If you're not sure, start with our pick; you can install a different distro next to it later.

<Callout type="info">**Our pick: Debian 13 with XFCE.** It's stable, runs on every CPU type, and XFCE is quick and easy to use. **Ubuntu 26.04 LTS with XFCE** is just as good if you prefer Ubuntu or follow Ubuntu guides.</Callout>

## Choose a distro

| Pick | If you want |
|---|---|
| **Debian 13** <Badge>Recommended</Badge> | A stable system that runs on any phone. |
| **Ubuntu 26.04 LTS** | Ubuntu, and the most apps and guides online. Supported until 2031. |
| **Ubuntu 24.04 LTS** | The previous Ubuntu LTS, for software that isn't ready for 26.04 yet. |
| **Kali Linux** | Security and penetration-testing tools (tools that need Wi-Fi or packet capture hardware won't work). |
| **Fedora 44** | The newest software. 64-bit phones only. |
| **Arch Linux** | A rolling distro you build up yourself. |
| **Manjaro ARM** | Arch-based, with Manjaro's defaults. 64-bit phones only; `sudo` doesn't work in Andronix yet. |
| **Alpine 3.24** | The smallest install. Uses musl, so some prebuilt apps (VS Code, Chrome) don't run. |
| **Void Linux** | An independent distro with its own package manager. |

Details for each (versions, CPUs, start scripts): [Supported distros](/reference/distros).

## Choose a desktop

| Pick | If you want |
|---|---|
| **XFCE** <Badge>Recommended</Badge> | A complete, familiar desktop that stays quick. Available on every distro. |
| **LXQt** | A lighter desktop, good for phones with less RAM. Every distro. |
| **MATE** | A classic desktop with menus at the top. Every distro. |
| **KDE Plasma** | The most complete desktop. Runs best with 4 GB of RAM or more; with less, the app warns you. Debian, Ubuntu 26.04 and Kali only. |
| **Command line only** | No desktop: the smallest, fastest install. You can add a desktop later. |

Screenshots of each: [Desktops](/reference/desktops).

## Changing your mind later

- **Another distro:** install it next to the first one, for example Debian next to Ubuntu.
- **Another desktop or edition of the same distro:** Andronix keeps one install per distro, so it replaces the one you have, and everything inside it is deleted. That includes Modded OS editions: Ubuntu KDE and Ubuntu XFCE can't be installed at the same time, and a Modded Ubuntu replaces a free Ubuntu. Copy your files out first: see [Back up your files](/use/backups).
  - **In the app:** install the distro again with the other desktop or edition; the app says it replaces the current one. A **Command line only** install can [add a desktop](/install/in-the-app#add-a-desktop-later) instead, and keeps your files.
  - **In Termux:** `andronix install debian --de lxqt --reinstall` (with your distro and desktop).
