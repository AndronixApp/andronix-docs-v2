In **standalone mode**, the Andronix app runs Linux itself. You pick a distro and a desktop, and the app installs it, starts it and shows the desktop on its own screen, with sound. There's no Termux to install, no command to paste, and no separate Termux:X11 app.

<Callout type="warning">Standalone mode is a **beta**. It works on many phones, but expect rough edges. Please tell us what goes wrong: see [Troubleshooting and reporting](/standalone/troubleshooting).</Callout>

<Shot name="standalone/desktop-toolbar" alt="Debian XFCE running inside the Andronix app, with the desktop toolbar at the bottom" caption="Debian with XFCE, running inside the app." />

## How it compares with Termux

| | In the app (standalone) | In Termux |
|---|---|---|
| What you install | Only the Andronix app | Andronix, Termux and Termux:X11 |
| How you install a distro | Tap through the app | Paste one command into Termux |
| Where the desktop shows | In the Andronix app | In the Termux:X11 app |
| Sound | Built in | Set up by Andronix in Termux |
| Updates to the installer | Come with app updates | `andronix update` |

Both can be on the same phone: distros you install in the app run in the app, and distros in Termux keep running in Termux. See [Standalone and Termux](/standalone/termux).
