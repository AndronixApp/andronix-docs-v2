Some graphics drivers can leave the desktop black. Andronix checks every desktop **45 seconds after it first draws**. If the screen is still one flat colour with nothing on it, Andronix fixes it by itself, one step per start, and tells you what it did:

1. **GPU acceleration off:** if GPU acceleration was on, it restarts the desktop without it.
2. **Safe mode:** it restarts the desktop in safe mode.
3. **VNC:** if it's still black in safe mode, it shows the desktop through VNC, another way of drawing it.

The loading screen stays up during the restart, and a banner at the top says what happened. Tap **Details** to see more, or **OK** to close it.

## Safe mode

Safe mode changes what made the desktop black on other devices. Details lists what it changed for you, from:

- Drawing in software, not on the graphics chip
- Lighter settings (desktop effects off)
- No window manager (windows without title bars)
- A fresh desktop session (windows from last time aren't reopened)

Safe mode is remembered for that distro. **Keep safe mode for &lt;distro&gt;** is on and marked "Recommended for this device".

- **To try the normal desktop again:** on Home, tap **⋮** next to the distro, then **Turn off safe mode**. It applies at the next start.
- **To start in safe mode yourself:** **⋮ › Start in safe mode** restarts the desktop in safe mode right away.

## Still black?

- On devices with a Linux kernel older than 4.8, desktops may stay black. See [The installer warns about an old kernel](/troubleshooting/install#the-installer-warns-about-an-old-kernel).
- Tap **Report a problem** on the Details sheet. In this beta it opens an email to us with the distro's name filled in. See [Troubleshooting and reporting](/standalone/troubleshooting).
