<Callout type="info">**Andronix 10.1 runs Linux in the app**, without Termux; it reaches phones in stages on Google Play. Have it? See [Linux in the app (10.1)](#linux-in-the-app-101) below.</Callout>
Andronix runs Linux on top of Android without GPU acceleration, so the desktop is drawn in software. These are the changes that make the biggest difference.

## Use the light profile

The light profile turns off desktop effects (compositing, animations), file thumbnails and some background apps, and uses 16-bit colour at 1280x720 over VNC. In Termux:

```bash copy
andronix tune debian --profile light
```

The change applies the next time you start the desktop. To go back, use `--profile balanced`. To see the current profile and your phone's RAM, run `andronix tune debian`.

<Callout type="info">On phones with **less than 3 GB of RAM**, desktop installs start with the light profile automatically.</Callout>

The light profile only adds its own settings on top of the desktop's, so your themes and any Modded OS look stay as they are.

## Pick a lighter desktop

From lightest to heaviest: **LXQt**, **XFCE**, **MATE**, **KDE Plasma**. KDE Plasma needs 4 GB of RAM or more. To switch in the app, copy your files out (see [Android files in Linux](/use/android-files)), remove the distro, and install it again with the lighter desktop.

## Lower the resolution

- **[Termux:X11](/desktop/termux-x11)** draws the desktop at the phone's resolution. If it feels slow, lower the resolution in the Termux:X11 app's preferences. (The light profile's VNC settings don't apply here.)
- **[VNC](/reference/vnc)**, if you use it: a smaller screen size is faster, for example `vncserver-start 1280x720`, and lower picture quality in the viewer helps too.

## Good habits

- Keep only the apps you use open; browsers use the most memory.
- Close other Android apps while you use the desktop.
- Turn off battery optimization for Termux, so Android doesn't slow it down in the background.
- Use the command line (`./start-debian.sh`) for work that doesn't need a desktop.


## Linux in the app (10.1)

Andronix draws the desktop in software, unless you turn on the experimental [GPU acceleration](/use/gpu). These are the changes that make the biggest difference in the app.

### Pick a smaller desktop size

**Standard** is the fastest desktop size; **Sharp** and **Native** draw more pixels. Change it from the desktop's toolbar or the distro's **⋮** menu on Home. See [Desktop size](/desktop/tablets#desktop-size).

### Pick a lighter desktop

From lightest to heaviest: **LXQt**, **XFCE**, **MATE**, **KDE Plasma**. KDE Plasma needs 4 GB of RAM or more. To switch, reinstall the distro with another desktop (this deletes it first, so [back it up](/use/backups)):

```bash copy
andronix install debian --de lxqt --reinstall
```

### Try GPU acceleration

On a device with a slower processor, the experimental GPU acceleration can make 3D apps faster; on fast devices, software drawing can be quicker. See [GPU acceleration](/use/gpu).

### Good habits

- Keep only the apps you use open; browsers use the most memory.
- Close other Android apps while you use the desktop.
- If the app shows **Keep Linux running**, tap it to turn off battery optimization for Andronix, so Android doesn't stop Linux in the background.
- Use the terminal (Home > **Your Linux** > **Terminal**) for work that doesn't need a desktop.
