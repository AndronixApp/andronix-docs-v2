Andronix draws the desktop in software, unless you turn on the experimental [GPU acceleration](/use/gpu). These are the changes that make the biggest difference in the app.

## Pick a smaller desktop size

**Standard** is the fastest desktop size; **Sharp** and **Native** draw more pixels. Change it from the desktop's toolbar or the distro's **⋮** menu on Home. See [Desktop size](/desktop/tablets#desktop-size).

## Pick a lighter desktop

From lightest to heaviest: **LXQt**, **XFCE**, **MATE**, **KDE Plasma**. KDE Plasma needs 4 GB of RAM or more. To switch, reinstall the distro with another desktop (this deletes it first, so [back it up](/use/backups)):

```bash copy
andronix install debian --de lxqt --reinstall
```

## Try GPU acceleration

On a device with a slower processor, the experimental GPU acceleration can make 3D apps faster; on fast devices, software drawing can be quicker. See [GPU acceleration](/use/gpu).

## Good habits

- Keep only the apps you use open; browsers use the most memory.
- Close other Android apps while you use the desktop.
- If the app shows **Keep Linux running**, tap it to turn off battery optimization for Andronix, so Android doesn't stop Linux in the background.
- Use the terminal (Home > **Your Linux** > **Terminal**) for work that doesn't need a desktop.

In Termux, the light profile (`andronix tune`) and the Termux:X11 and VNC resolution settings help too: see [Make it faster in Termux](/termux/performance).
