A backup saves your whole distro (your files, installed apps and settings) to one file. You can restore it later, after reinstalling Termux, or on another phone.

## Back up

First, stop the desktop and `exit` the distro, so no files change while it's saved. Then, in Termux:

```bash copy
andronix backup debian --to storage
```

This writes `andronix-debian-<date>.tar.gz` to the **Andronix/backups** folder in your phone's storage. It's safe there even if you uninstall Termux, and you can see it in your file manager. If Termux doesn't have storage access yet, Android asks you for it.

<Callout type="info">Without `--to storage`, the backup goes to Termux's home folder instead. That folder is deleted if you uninstall Termux or clear its data. You can also give your own file name: `andronix backup debian ~/my-debian.tar.gz`.</Callout>

## Restore

```bash copy
andronix restore
```

With no file name, it lists the backups it finds in your phone's storage and in Termux's home folder, newest first, and lets you pick one. You can also name the file: `andronix restore /sdcard/Andronix/backups/andronix-debian-20260926.tar.gz`.

If the same distro is already installed, it asks before replacing it. When it's done, start the distro as usual.

## On another phone

Backups work on any phone with the same CPU type (most phones are arm64). Install Termux on the new phone, [install Andronix without the app](/install/without-the-app) or through the app, then copy the backup file over and run `andronix restore`.


## Linux in the app (10.1)

There's no backup for distros in the app yet. To keep your files, copy them out: your Linux home shows in Android's **Files** app under **Andronix**, and you can save files to `~/Android/Download` or `~/Android/Documents` in Linux, which appear in **Download/Andronix** and **Documents/Andronix** on your phone. See [Android files in Linux](/use/android-files).

You can bring a backup from Termux **into** the app: see [Move a distro from Termux into the app](/install/standalone-and-termux#move-a-distro-from-termux-into-the-app).
