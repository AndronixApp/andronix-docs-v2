This guide covers installing a Modded OS edition with the **Andronix app 10 (Andronix 2.0)**: the five Modded 2.0 editions, and the Classic editions for people who bought them before. It takes a few taps.

<Callout type="info">Using the Andronix app 8.x? Its guide is in the [App 8.x (Classic) docs](/v8/modded-os/modded-os-installation).</Callout>

<Callout type="info">**Upgrading from an older Modded OS?** If you installed a Modded OS with the old Andronix app (8.x or earlier), see [Upgrading from an older Modded OS](/modded-os/upgrade): back up your files, uninstall the old version, then install the new one.</Callout>

## Before you start

- **Sign in** to the Andronix app. Your purchases are linked to your account.
- **A 64-bit phone:** Modded OS isn't available on 32-bit phones; the app tells you if yours is one.
- **One install per distro:** a Modded edition is installed into the folder of the distro it's built on, so it can't sit next to the free distro of the same base, or another edition built on it. For example, Modded 2.0 Ubuntu KDE replaces the free Ubuntu. If one is already there, the install stops and tells you; to replace it, add `--reinstall` to the command. It asks before deleting anything, so [back up](/use/backups) what you want to keep first.
- **Download limits:** each account can download a Modded OS a set number of times per day and per month. Most people never reach the limit, and Premium raises it. If you need more for a good reason, [contact us](mailto:support@andronix.app).

## 1. Pick an edition

Open the **Modded OS** tab. It lists the Modded 2.0 editions, the Modded Pass and Andronix Complete. If you bought a Modded OS before Andronix 2.0, your **Classic** editions are listed further down, under **Archived — yours to keep**.

## 2. Buy it (if you don't own it yet)

Tap an edition you don't own, or the **Modded Pass** or **Andronix Complete** offer. The Google Play purchase sheet opens; pay there as you would for any app. When the purchase is done, the edition shows as **Owned**.

## 3. Install it

The edition installs inside the app:

1. Tap your edition, then install it.
2. **Set up your user**: enter a user name and a password, as for a free distro. Modded editions come without a user, so the app always asks.
3. The install screen shows each step. When it's done, tap **Open the desktop**.

<AppShot name="app10-sa-modded-installing" alt="Installing Ubuntu Modded in the app: the current step and the Steps list" />

The edition installs into its base distro and shows on Home under **Your Linux** with its base distro's name and **Modded**. In the app, Modded OS needs a 64-bit ARM device and a Linux kernel 4.8 or newer.

If the app says:

- **That token is for another edition:** go back and pick this edition again.
- **Early access: Premium:** this edition is in early access for Andronix Premium and Modded Pass owners.
- **The download link expired:** go back and start the install again.

To reinstall an edition in the app, install it again. The app asks you to confirm first, because everything inside it is deleted.

## 4. Start the desktop

When the install is done, tap **Open the desktop**. Later, open it from Home under **Your Linux**: your edition is listed with its base distro's name and **Modded**. See [Your Linux on Home](/use/your-linux).

## Classic editions

The Classic editions (the original Modded Ubuntu XFCE, Ubuntu KDE, Debian and Manjaro) install the same way: tap the edition under **Archived — yours to keep** (it shows **Owned**), then follow steps 3 and 4. They're free for everyone who bought them before, and aren't sold anymore.

## Remove a Modded OS

On Home, under **Your Linux**, tap **⋮** next to the edition, then **Remove**, and confirm. See [Uninstall a distro](/install/uninstall).

Installed a Modded OS in Termux? See [Modded OS in Termux](/termux/modded-os).
