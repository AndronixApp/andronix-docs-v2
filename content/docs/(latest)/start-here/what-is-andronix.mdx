Andronix puts a full Linux distro, like Debian, Ubuntu or Fedora, on your Android phone or tablet. You get a real Linux command line with the distro's own packages, and a desktop (XFCE, LXQt, MATE or KDE Plasma) you can use on the phone or from another device. It doesn't need root and doesn't change anything on Android itself.

## How it works

- **The Andronix app** installs the distro and runs it **itself**, with no other app needed. Its desktop opens on the app's own screen, with sound. See [Install in the app](/install/in-the-app).
- **proot**, built into the app, lets the distro run as if it had its own root filesystem, without root on the phone. Nothing on Android itself is changed.
- **Your distro** is the real thing: its own package manager (`apt`, `dnf`, `pacman` and so on), a normal user with `sudo`, and a desktop: XFCE, LXQt, MATE or KDE Plasma.
- **The app also sells** [Modded OS](/modded-os/modded-os), our themed editions with apps already set up. The free distros are free.

## What happens when you install a distro

1. The app checks your device, gets proot ready and finds the best download.
2. It downloads a ready-made image of the distro, checks it, unpacks it and sets it up.
3. Inside the distro, it installs your desktop and a web browser with the distro's own package manager.
4. It sets up your user, with the name and password you chose.

Then tap **Open the desktop**. Your distro stays on Home under **Your Linux**; see [Your Linux on Home](/use/your-linux). You can [update it](/use/updates) or [remove it](/install/uninstall) at any time.

On a phone with Android 7 or without a 64-bit ARM processor, or if you want the command-line installer, Andronix runs the distro inside Termux instead: see [Termux (older phones)](/termux/with-the-app).
