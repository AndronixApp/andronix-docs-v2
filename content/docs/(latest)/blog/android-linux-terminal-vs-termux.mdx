Since 2025, some Android phones have a built-in way to run Linux: the **Terminal** app, turned on with **Linux development environment** in Developer options. People often ask whether it replaces Termux and Andronix. The short answer: on the phones that have it, it's a great option for some jobs; most phones don't have it, and for a full desktop on the phone, Termux with Andronix is still the simpler route.

<Callout type="info">This is a fast-moving feature. What follows is accurate as of October 1, 2026, with sources linked; check your own phone's Developer options for what it offers today.</Callout>

## What Android's Linux Terminal is

- **A Debian virtual machine.** The Terminal app runs "a slightly modified Debian-based OS image" in a virtual machine, using the Android Virtualization Framework (AVF). It has its own Linux kernel, separate from Android's. ([Android Open Source Project](https://source.android.com/docs/core/virtualization/usecases))
- **Turned on in Developer options.** On supported phones: **Settings › System › Developer options › Linux development environment**. The Terminal app then downloads the Debian image, about 567 MB when it launched. ([Android Authority, March 2025](https://www.androidauthority.com/android-linux-terminal-app-available-3532999/))
- **Stable on Pixel phones since the March 2025 update**, after Android 15 beta builds. (Same source.)
- **Graphical apps** came later, first in Android Canary builds on Pixel 6 and newer in 2025, and on some Samsung phones. Performance and support vary by device and Android version. ([Android Authority, August 2025](https://www.androidauthority.com/run-desktop-linux-apps-on-android-how-to-3586539/), [July 2026](https://www.androidauthority.com/samsung-linux-terminal-galaxy-z8-foldables-3688560/))

## Which phones have it

The Linux Terminal needs a chip that can run **non-protected virtual machines**. As of mid-2026, that includes Google Tensor (Pixel), Samsung Exynos 2500 and 2600, and some MediaTek chips. Qualcomm Snapdragon chips such as the Snapdragon 8 Elite Gen 5 don't support it, so Snapdragon versions of Galaxy phones (including US models) don't get the Terminal, while Exynos versions of the same phones can. ([Android Authority, July 2026](https://www.androidauthority.com/samsung-linux-terminal-galaxy-z8-foldables-3688560/))

To check your phone: open Developer options and look for **Linux development environment**. If it isn't there, your phone doesn't offer it.

Most Android phones in use today are older, budget, or Snapdragon-based, and don't have it. Termux runs on Android 7 and newer on almost any phone.

## How it compares

| | Android Linux Terminal | Termux + Andronix |
|---|---|---|
| How Linux runs | A virtual machine with its own kernel | proot, on Android's kernel, as Termux's processes |
| Phones | Only phones whose chip and maker support it (see above) | Android 7 or newer, nearly any phone (arm64, arm, x86, x86_64) |
| Distros | Debian | Debian, Ubuntu (26.04 and 24.04), Kali, Fedora, Arch, Manjaro, Alpine, Void |
| Desktop on the phone | Depends on the device and Android version | XFCE, LXQt, MATE or KDE Plasma, full screen with Termux:X11 |
| Sound | Depends on the device | Through the phone's speakers, set up for you |
| Docker, systemd services, kernel features | Closer to a normal Linux machine, because it has its own kernel | Not available under proot (no Docker, Snap or Flatpak) |
| Android's "signal 9" process limit | Doesn't apply the same way: Linux runs in a VM, not as app child processes | Applies on Android 12+; [turn it off once](/troubleshooting/signal-9) |
| Install | A switch in Developer options | One command in Termux, or the Andronix app |

## When to use which

**Use Android's Linux Terminal** if your phone has it and you want:

- a Debian environment with its own kernel, for things proot can't do (container tools, kernel features, software that needs real system calls);
- something built into Android, with nothing extra to install.

**Use Termux with Andronix** if:

- your phone doesn't have the Linux Terminal (most Snapdragon and older phones);
- you want Ubuntu, Kali, Fedora, Arch or another distro, not only Debian;
- you want a full desktop like XFCE or KDE Plasma on the phone today, with sound;
- you want to reach the desktop from a laptop over VNC (`vncserver-start --lan`).

You can also use both on a phone that supports the Terminal: they don't interfere with each other.

## Common questions

### Will the Linux Terminal replace Termux?

They do different jobs. Termux is an Android app with its own Linux-like userland and packages, and runs on almost every phone. The Linux Terminal is a full Debian VM on phones that support it. Google has described the Terminal's aim as bringing more Linux apps and tools to Android, not as a separate desktop environment. ([Android Authority, March 2025](https://www.androidauthority.com/android-linux-terminal-purpose-3535765/))

### My Galaxy phone doesn't show "Linux development environment". Why?

Most likely it has a Snapdragon chip, which doesn't support the kind of virtual machine the Terminal needs. Termux with Andronix works on it.

### Is proot slower than a virtual machine?

They're slow in different places. proot adds overhead to system calls (opening files, starting processes), so package installs and heavy file work are slower than native. A VM runs its own kernel at near-native speed, but needs memory reserved for the VM. For desktop apps, browsing and coding, both are usable on a recent phone; neither uses the GPU fully everywhere.

### Does Andronix work on new Android versions?

Andronix needs Android 7 or newer, and Andronix 2.0 was tested up to Android 16. On Android 12 and newer, turn off the phantom process limit once: [Process completed (signal 9)](/troubleshooting/signal-9).
