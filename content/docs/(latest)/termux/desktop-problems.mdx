This page is for Andronix with **Termux**, on phones that can't run Linux in the app (Android 7, or no 64-bit ARM processor), or if you use the command-line installer. For Linux in the app, see [Black screen and safe mode](/troubleshooting/black-screen).

This page covers problems with the desktop, over [Termux:X11](/termux/termux-x11) or [VNC](/termux/vnc).

## Termux:X11 doesn't open, or a box covers the desktop

- **A "send you notifications?" box** (Android 13 and newer, the first time): tap **Allow**. Your desktop is behind it.
- **Termux says "Desktop is running" but the app doesn't come to the front:** open Termux:X11 from your app drawer.
- **The extra-keys bar is missing, or covers the bottom panel:** Andronix hides Termux:X11's extra-keys bar the first time you start a desktop so the bottom panel shows. Swipe down with three fingers in Termux:X11 to bring it back (or turn it on in Termux:X11 settings).
- **"Termux:X11 isn't installed":** download `termux-x11-universal-debug.apk` from the [Termux:X11 nightly release](https://github.com/termux/termux-x11/releases/tag/nightly) and install it. See [Start the desktop](/termux/termux-x11).

## The desktop disappears and Termux says "signal 9"

If Termux shows `[Process completed (signal 9) - press Enter]`, Android 12 or newer stopped your distro because it started many processes. A desktop does that quickly. Turn it off once: see [Process completed (signal 9)](/troubleshooting/signal-9).

## The screen stays black

- **Termux:X11:** some phones' graphics drivers need a different drawing mode. Stop the desktop (`andronix desktop stop`), then open it with:

  ```bash copy
  ANDRONIX_X11_ARGS=-legacy-drawing andronix desktop
  ```

  If the colours look swapped, use `-force-bgra` instead.
- **Old kernels:** on kernels older than 4.8 (run `uname -r` in Termux to check), the desktop may stay black. Try `andronix desktop --legacy-drawing`, then VNC; the command line always works. See [The installer warns about an old kernel](/termux/install-problems#the-installer-warns-about-an-old-kernel).
- **Installed before an update:** run `andronix update` in Termux. It applies Andronix's latest fixes to the desktop session.

## The desktop didn't start (VNC)

If `vncserver-start` says **The desktop didn't start**, stop it and start it again:

```bash copy
vncserver-stop 1
vncserver-start
```

If it still fails, the error box shows the path of a log file (for example `/tmp/andronix-vnc-1.log`). Share it when you ask for help.

## The desktop closes when I leave Termux

The desktop runs inside your Termux session. Closing that session, or typing `exit` in the distro, stops the desktop too.

**Fix:** keep the Termux session open while you use the desktop. Switch to your VNC viewer with the app switcher instead of closing Termux. For a second command line, open a new Termux session from the sidebar.

## The desktop is slow

Switch the distro to the light profile from Termux, then restart the desktop:

```bash copy
andronix tune debian --profile light
```

It turns off desktop effects, thumbnails and some background apps, and uses 16-bit colour. Phones with less than 3 GB of RAM get it automatically. On phones with less than 4 GB of RAM, pick XFCE or LXQt rather than KDE Plasma. See [Making a desktop lighter](/reference/desktops#making-a-desktop-lighter).

## Firefox opens in a small window

Firefox opens in a smaller window the first time; double-tap its title bar to maximize, and it remembers.

## I can't connect from my computer

By default, the desktop only accepts connections from the phone itself. Start it with `vncserver-start --lan` to allow other devices on your network. See [VNC on other devices](/termux/vnc#vnc-on-other-devices).

## Still stuck?

- Every install, remove, backup and restore writes a log to `~/.andronix/logs/` in Termux. Include the latest one when you ask for help.
- [Report a problem](/troubleshooting/report-a-problem) from the Andronix app. It attaches your phone's details and gives you a report ID.
- Ask on our [Discord](https://chat.andronix.app), or email [support@andronix.app](mailto:support@andronix.app).
