This page is for Andronix with **Termux**, on phones that can't run Linux in the app (Android 7, or no 64-bit ARM processor), or if you use the command-line installer. For Linux in the app, see [The desktop in the app](/desktop/in-the-app).

<Callout type="info">**The main way to open your desktop is [Termux:X11](/termux/termux-x11)**, full screen on the phone with `andronix desktop`. Use VNC when you want the desktop on another device, like a laptop or tablet, or prefer a VNC viewer app.</Callout>

VNC lets you see and use your distro's desktop in a VNC viewer app. This page shows you how to start and stop the VNC server, connect to it, tweak its resolution and picture quality, and access it from other devices on your network.

## Operating the VNC Server

Let's learn how to operate the VNC server, including starting, stopping and debugging it.

<Callout type="info">Make sure you have started your distro and are in the distro shell, i.e. you see your username followed by `@localhost` (for example `alex@localhost`) in Termux.</Callout>

<Callout type="info">These steps are for distros installed with Andronix 2.0. On a Classic Modded OS or a distro from before Andronix 2.0, see [VNC on an old install](/pre-2.0/old-install-guides#vnc-on-an-old-install).</Callout>

### Starting a VNC server

<Steps>
<Step>

### Start VNC Server

If you are on the VNC server page in Andronix, the app has already copied the necessary command to your clipboard. Just paste it in Termux (in the distro shell, where you see your username, like `alex@localhost`) and run it.

```bash copy
vncserver-start
```


</Step>

<Step>

### Pick a Screen Size

You're asked to pick a screen size. Press **Enter** to pick **Auto**, which fits your VNC viewer. You can also pick HD (1280x720), Full HD (1920x1080), QHD (2560x1440) or type your own size.

If you haven't set a desktop password yet, you're asked for one now (6 to 8 characters).

When the desktop is up, you'll see a **Desktop is running** box with the address to connect to, `localhost:1`.

<Callout type="warning">Keep this Termux session open while you use the desktop. Closing it, or typing `exit`, stops the desktop too. To use the Termux command line at the same time, open a new session from the Termux sidebar (swipe in from the left edge).</Callout>

</Step>

<Callout type="warning">Always remember to **stop the VNC server** by running `vncserver-stop` before exiting the distro.</Callout>

### Stopping a VNC server

Stop the VNC server whenever you're done using your distro or are about to exit it. To do so, run the following command in the distro shell:

```bash copy
vncserver-stop
```

It asks which display to stop. Press **Enter** to pick `:1`, the usual one. To skip the question, run `vncserver-stop 1`.

## VNC Settings

<Callout type="info">These instructions assume that you have started your distro and are inside the distro shell (not the Termux shell).</Callout>

### Setting a screen size

Pass the size you want when you start the desktop, and you won't be asked:

```bash copy
vncserver-start 1920x1080
```

<Callout type="info">You can replace 1920x1080 with any size, written as WIDTHxHEIGHT. There's no file to edit.</Callout>

### Changing the desktop password

Delete the saved password, then start the desktop. It asks you for a new one:

```bash copy
vncserver-stop 1
rm ~/.config/tigervnc/passwd
vncserver-start
```

### How to change the picture quality in VNC

If you're using bVNC, you don't need to change anything; it adjusts the quality automatically.

If you're using RealVNC Viewer, connect to the VNC server and tap the _(i)_ button at the top. Then change
**Picture Quality** to **High**, or to whatever quality you prefer.

## VNC on other devices

<Callout type="info">You can access the distro running on your phone from any other device on your network, like a laptop or a tablet.</Callout>

By default, the desktop only accepts connections from the phone it runs on. To let other devices connect, start it with `--lan`:

```bash copy
vncserver-start --lan
```

The **Desktop is running** box then says the desktop is reachable from your whole network.

<Callout type="warning">With `--lan`, anyone on the same network who knows your desktop password can connect, and VNC traffic isn't encrypted. Only use it on networks you trust, like your home Wi-Fi or your own hotspot, and stop the desktop when you're done.</Callout>

Make sure both devices are on the same network. If you don't have access to Wi-Fi, turn on the hotspot on the phone running Linux and connect the other device to it. Then open a new Termux session (swipe in from the left edge to open the sidebar) and type:

```bash copy
ip a
```

Copy the **WLAN IP** address (e.g. _192.168.xx.xx_). On the other device, connect your VNC viewer to this IP address with display number 1 (e.g. _192.168.xx.xx:1_).

To go back to phone-only access, run `vncserver-stop`, then `vncserver-start` without `--lan`.
