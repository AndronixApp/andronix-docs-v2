This page is for Andronix with **Termux**, on phones that can't run Linux in the app (Android 7, or no 64-bit ARM processor), or if you use the command-line installer. For Linux in the app, see [Install in the app](/install/in-the-app).

<Callout type="info">You need Termux only to run Linux **in Termux**. To run it in the app, skip this page: see [Install in the app](/install/in-the-app).</Callout>

Termux is the terminal app your distro runs in. Andronix needs a current build of Termux; the very old Play Store version from 2020 doesn't work anymore.

## Which Termux works

| Termux build | Works with Andronix | Notes |
|---|---|---|
| **F-Droid** | Yes | Android 7 or newer. The Andronix app recommends it. |
| **GitHub** (the Termux project's releases) | Yes | Android 7 or newer. The same app as F-Droid, but signed differently, so don't mix the two. |
| **Google Play Store, current build** | Yes | Android 11 or newer. |
| **Google Play Store, old build (2020, version 0.101)** | No | Its package servers are gone, so installs fail before they start. Replace it (see below). |

Termux plugins that share Termux's data, like Termux:API, must come from the same source as Termux itself, because apps from different sources are signed differently.

**Termux:X11 is different:** it's only published on GitHub, and it works with every current Termux build: F-Droid, GitHub and Play Store. You'll get it in [Step 3](/termux/termux-x11).

### Check which one you have

Open Termux and run:

```bash copy
echo $TERMUX_APK_RELEASE
```

It prints `F_DROID`, `GITHUB` or `GOOGLE_PLAY_STORE`. If it prints nothing, or Termux's **About** screen shows version 0.101, you have the old build: follow the steps below.

## Manual method

Use these steps to install Termux from F-Droid or GitHub, or to replace the old Play Store build. Andronix never bundles or hosts Termux: it always comes from the Termux project.

<Callout type="warning">Uninstalling Termux deletes everything in it, including any distros. If you have a distro you want to keep, [back it up](/use/backups) to your phone's storage first.</Callout>

<Steps>
<Step>

### Uninstall the old Termux

If you have the old Play Store build, uninstall it first. Apps from different sources can't be installed over each other.

</Step>

<Step>

### Download Termux

Get Termux from the Termux project:

- **F-Droid** (recommended): https://f-droid.org/packages/com.termux/. The F-Droid client app also keeps Termux updated for you.
- **GitHub:** the Termux project's releases at https://github.com/termux/termux-app/releases.
- **Google Play** (Android 11 or newer): search for Termux by Fredrik Fornwall.

In the Andronix app, **Get Termux** opens these same pages.

<Callout type="info">Android may warn that files like this can harm your device. That generic warning shows for any app installed from outside the Play Store.</Callout>

</Step>

<Step>

### Allow installing from this source

Tap the downloaded file. If you see a popup like this one, tap **Settings** and turn on the toggle:

<Imagera src="/images/unknown_sources.png" alt="Android popup blocking installs from unknown sources, with a Settings button" />

<Imagera src="/images/allow_unknown_sources_radio.png" alt="The Allow from this source toggle in Android settings" />

Then go back until you see the install dialog.

</Step>

<Step>

### Install

Tap **Install**.

<Imagera src="/images/install_termux.png" alt="Android install dialog for the Termux app" />

</Step>

<Step>

### Open Termux once

Open Termux and wait until it shows a prompt (`~ $`). The first start sets up its own files.

</Step>
</Steps>

<Callout type="warning">In your phone's settings, turn off **battery optimization** for Termux, so Android doesn't stop it while it installs or runs your distro.</Callout>
