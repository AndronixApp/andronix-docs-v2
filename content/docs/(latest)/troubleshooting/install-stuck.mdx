These three steps are where most installs stop. All three download something, so the cause is almost always the connection, not your phone or the distro. This page is for installs in the app and in Termux.

## What each step does

| Step | What it downloads | If it stops |
|---|---|---|
| **Finding the best download** | Nothing big yet. It looks for the distro on our download server (`dl.andronix.app`), then on Docker Hub, then on the distro's own site. | Your phone couldn't reach any of them. This is a network or DNS problem. |
| **Downloading** (for example **Downloading Debian 13**) | The distro itself. The screen shows how much is done. | The connection dropped or became very slow, or the phone ran out of space. |
| **Refreshing package lists** | The list of packages from the distro's own servers (for example Debian's, Arch's or Manjaro's mirrors). | Those servers didn't answer, or the connection dropped. |

**Stuck or just slow?** If the amount done on **Downloading** keeps growing, the install is working; a slow connection only makes it longer. A whole install usually takes 5 to 30 minutes.

## Try these, in order

1. **Check the phone is online.** Open a website in your browser.
2. **Switch networks.** Wi-Fi to mobile data, mobile data to Wi-Fi, or another Wi-Fi. Some networks block our download server or Docker Hub.
3. **Turn off what filters the connection** while you install: a VPN, an ad blocker, a firewall app, or a Private DNS that blocks ads. In Android's settings, set **Private DNS** to **Automatic** or **Off**.
4. **Allow data for Andronix.** If your phone can block Wi-Fi or mobile data per app (some Xiaomi phones do, under **Restricted data usage**), allow both for Andronix (and for Termux, if you use it).
5. **Check the date and time.** Turn on automatic date and time in Android's settings. Secure downloads fail when the clock is wrong.
6. **Keep the app open** until the install finishes: the Andronix app (or Termux) on screen, and the screen on. See [Keep the install running](#keep-the-install-running).
7. **Try again.** In the app, tap **Try again**. In Termux, run the same install command again.

<Callout type="info">Private DNS itself is fine: Andronix looks up servers through Android, so it uses your Private DNS. It only gets in the way when that DNS blocks some addresses, as ad-blocking ones do.</Callout>

## Not enough space

The download needs room for the downloaded file and the unpacked system at the same time. If there isn't enough, the install stops with **Not enough space** and says how much to free up.

- Free up what it asks for (old videos, app caches), then try again.
- In the app, the desktop picker shows how much each desktop needs and greys out the ones that don't fit.
- A smaller desktop (XFCE or LXQt) or **Command line only** needs less. See [Requirements](/start-here/requirements).

## Keep the install running

In the app, the install can keep going in the background with its notification. But some phones close apps in the background (Infinix, Tecno, itel, Xiaomi, Redmi and POCO most often), and the install then stops part-way. To avoid that:

- Keep Andronix open on screen, with the screen on, until it finishes. Don't swipe it away from recent apps.
- Let Andronix run in the background: in its **App info**, under **Battery**, choose **Unrestricted** (or **Don't optimize**).
- On Android 12 and newer, turn off Android's child process limit: see [Process completed (signal 9)](/troubleshooting/signal-9).

If Android stops the install, the app shows **Keep the install running** with the settings to check. Fix them, then tap **Try again**.

In Termux, keep Termux open until the install finishes, and turn off battery optimization for Termux.

## Still stopping? Send a report

Send a report **right after** it stops, so the log of that install is attached:

- **In the app:** tap **Report a problem** on the failed install screen. **Attach my last install** adds the step it stopped at and the installer's log, with personal details removed.
- **In Termux:** run `andronix report`.

You get a report ID like `AX-7K3Q9M`. Quote it when you write to us. See [Report a problem](/troubleshooting/report-a-problem).
