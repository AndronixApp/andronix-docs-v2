This page shows how to get sound working in your distro, so you can listen to music from Spotify (or anything else) through your phone's speakers while you code. We use PulseAudio to route sound out of the PRoot container to your phone's speakers.

<Callout type="info">Modded OS has sound output through the phone's speakers enabled out of the box.</Callout>

Follow these steps in order to enable sound output:

<Steps>
<Step>

### Close Distro

If your distro is running, close it by running `exit` inside Termux. _Skip this step if your distro isn't running._

```bash copy
exit
```

</Step>

<Step>

### Run Commands

Run the following command in **Termux (not inside Linux)**:

```bash copy
pkg install wget && wget https://andronixos.sfo2.cdn.digitaloceanspaces.com/OS-Files/setup-audio.sh && chmod +x setup-audio.sh && ./setup-audio.sh
```

</Step>

<Step>

### Start PulseAudio Server

Start the PulseAudio server:

```bash copy
pulseaudio --start
```

</Step>
</Steps>
