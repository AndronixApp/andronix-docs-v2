This page shows how to reach your phone's internal storage from inside your Linux distro. On distros from the current installer, it's one command in Termux.

## Storage on a new install

Distros from the current installer share your phone's internal storage at `/sdcard` automatically. Termux just needs permission to read it.

<Steps>
<Step>

### Give Termux storage access

In Termux (not inside the distro), run:

```bash copy
termux-setup-storage
```

Termux will now ask for Storage permission. **Allow the Storage permission**.

</Step>

<Step>

### Restart the distro

If the distro is running, `exit` it and start it again, for example with `./start-debian.sh`.

</Step>

<Step>

### Check

Inside the distro, run `ls /sdcard`. You should see your phone's folders, like `Download` and `DCIM`.

</Step>
</Steps>

### Sharing other folders

To share another Termux folder with the distro, add a line to a file in `~/<distro>-binds/` in Termux, the same way as with the old installer. For example, to make Termux's `~/projects` folder appear at `/projects` in Debian:

```bash copy
mkdir -p ~/debian-binds
echo 'command+=" -b /data/data/com.termux/files/home/projects:/projects"' > ~/debian-binds/projects.sh
```

Restart the distro for the change to take effect.

## Storage on an old install

<Callout type="warning">These steps are for distros installed with the **old installer**. On the current installer, the start script no longer needs editing; see [Storage on a new install](#storage-on-a-new-install).</Callout>

<Steps>
<Step>

### Termux Session

First, open a new Termux session (swipe from the left edge to the right) and type:

```bash copy
termux-setup-storage
```

Termux will now ask for Storage permission. **Allow the Storage permission**.

</Step>

<Step>

### Open Start File

Once that's done, type:

```bash copy
nano start-(distroname).sh
```

<Callout type="warning">Make sure to replace **(distroname)** with your specific distro name.</Callout>

</Step>

<Step>

### Search

Now look for this line:

```bash copy
#command+=" -b /sdcard"
```

</Step>

<Step>

### Edit

If you find it, remove the leading `#` so the line reads:

```bash copy
command+=" -b /sdcard"
```

</Step>

<Step>

### Add the line

If you can't find the line, add the line above as shown in the screenshot below.

<Imagera src="/images/strorage_ss.png"/>

</Step>

<Step>

### Save

When you're done, press `Ctrl+X`, then `Y`, and then `Enter`. Now start your Linux system and run `cd /`. You should see a folder named `sdcard`, which means you have successfully mounted your internal storage.

</Step>
</Steps>
