title: Accessing Internal Storage

This page shows how to make your phone's internal storage available inside your Linux distro. It only takes one command in Termux and a one-line edit to your distro's start script.

<Steps>
<Step>

### Termux Session

First, open a new Termux session (swipe from the left edge to the right) and type:

```bash copy
termux-setup-storage
```

Termux will now ask for Storage permission. **Allow the Storage permission**.

</Step>

<Step>

### Open Start File

Once that's done, type:

```bash copy
nano start-(distroname).sh
```

<Callout type="warning">Make sure to replace **(distroname)** with your specific distro name.</Callout>

</Step>

<Step>

### Search

Now look for this line:

```bash copy
#command+=" -b /sdcard"
```

</Step>

<Step>

### Edit

If you find it, remove the leading `#` so the line reads:

```bash copy
command+=" -b /sdcard"
```

</Step>

<Step>

### Add the line

If you can't find the line, add the line above as shown in the screenshot below.

<Imagera src="/images/strorage_ss.png"/>

</Step>

<Step>

### Save

When you're done, press `Ctrl+X`, then `Y`, and then `Enter`. Now start your Linux system and run `cd /`. You should see a folder named `sdcard`, which means you have successfully mounted your internal storage.

</Step>
</Steps>
