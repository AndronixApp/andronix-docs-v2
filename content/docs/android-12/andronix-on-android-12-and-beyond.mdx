This page explains the phantom process killer introduced in Android 12, why it breaks Termux and Andronix, and how to turn it off on your device.

<Callout type="error">If you are seeing the **Process completed (signal 9) - press Enter** error in Termux, follow the steps on this page to fix it.</Callout>

## The Problem

Android 12 added a mechanism that monitors forked child processes started by apps and kills them if more than the
default 32 are running. In simpler words, Android now monitors the number of child processes spawned by an app, and if
that number exceeds the permitted limit, it kills them.

This has led to a lot of power-user apps like Termux, Tasker, Andronix and Debian NoRoot breaking on Android 12 and 12L devices.
There is nothing we can do about this on our side, since the change is part of Android's code.

### More Information

Issue on Termux's repository:
[Android 12 Phantom Processes Killed (Process completed (signal 9) - press Enter)](https://github.com/termux/termux-app/issues/2366)

<Callout type="info">
The good news is that Google has included a toggle to turn off the phantom process killer in Android 12L and 13, but OEMs like **Xiaomi, Samsung, etc.** have not bothered to merge this change into their Android skins.
</Callout>

[More information on the proposed solution](https://www.xda-developers.com/android-13-phantom-process-toggle)

## Solutions

Follow the instructions below for your Android version. If you are on stock Android, start with the first fix. If you use a skinned ROM like OneUI or MIUI, jump to the second one.

### Fix for Stock Android 12L and beyond

<Callout type="info">
This fix might not work on your device, as OEMs can choose to leave out changes Google pushes to the Android Open Source Project. If you are using a skinned Android ROM like Samsung's OneUI, Xiaomi's MIUI, Oppo's ColorOS, etc., try the next fix instead.
</Callout>

#### Video Tutorial for Stock Android 12L+

<YoutubeEmbed id={"mjXSh3yq-I0"}/>

Follow the steps below to turn off the phantom process killer:

<Steps>
<Step>

### Enable Developer Options

First, enable **Developer Options** in your settings. To do this, go to *Settings > About Phone* and find the **Build Number**.
<Imagera src="/images/android-12-fix/1.jpeg"/>
<Imagera src="/images/android-12-fix/2.jpeg"/>

</Step>

<Step>

### You're a developer now!

Tap the build number repeatedly until you see a toast notification along the lines of *You are now x steps away from being a
developer*.
<Imagera src="/images/android-12-fix/3.jpeg"/>

</Step>

<Step>

### Authenticate

You might be asked to authenticate yourself. Do so, then continue.
<Imagera src="/images/android-12-fix/4.jpeg"/>

</Step>

<Step>

### Turn On Developer Options

Now, go to *Settings > System > Developer Options* and turn on Developer Options on the next screen.
<Imagera src="/images/android-12-fix/5.jpeg"/>

</Step>

<Step>

### Find the Feature Flags

Find the section named **Feature Flags** and tap it to open it.
<Imagera src="/images/android-12-fix/6.jpeg"/>

</Step>

<Step>

### Turn off the Phantom Process Killer

Find the **settings_enable_monitor_phantom_procs** switch and turn it off.
<Imagera src="/images/android-12-fix/7.jpeg"/>

</Step>

<Step>

### All done!

You are now all set! ✅

</Step>
</Steps>

### Fix for OneUI, MIUI and other non-stock Android 12L and beyond

#### Video Tutorial for OneUI, MIUI and other non-stock Android 12L+

<YoutubeEmbed id={"mjXSh3yq-I0?start=117"}/>

Follow the steps below to turn off the phantom process killer using ADB from another device:

<Steps>
<Step>

### Install ADB

Make sure you have the Android Debug Bridge (ADB) installed on your other device. You can
follow [this guide on XDA Developers](https://www.xda-developers.com/install-adb-windows-macos-linux/) to install ADB
on Windows, macOS, or Linux.

<Callout type="info">
If you don't have a computer, you can follow the method shown in the video above to install ADB on your Android device itself.
</Callout>

</Step>

<Step>

### Check ADB Devices

After installing ADB, confirm that your device is connected:
```bash copy
adb devices
```

</Step>

<Step>

### Run the Commands

You should see your device listed in the output of the command above. Now run the following commands:
```bash copy
adb shell "/system/bin/device_config set_sync_disabled_for_tests persistent"
```
```bash copy
adb shell "/system/bin/device_config put activity_manager max_phantom_processes 2147483647"
```
```bash copy
adb shell settings put global settings_enable_monitor_phantom_procs false
```

</Step>

<Step>

### All done!

You should be all set! ✅

</Step>
</Steps>
