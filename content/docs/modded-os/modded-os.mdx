Modded OS are Linux distros that our team has modified for maximum performance. Each one ships with the essential software preinstalled, and the themes and icons are chosen to match every element of the system. This page explains what Modded OS offer, when to pick one, and how to get started.

## When should you choose Modded OS?

Choose Modded OS whenever you don't want to spend your time optimizing things, fixing theming issues, or hunting down the right PPA to install a working version of some software. In short, it lets you enjoy Linux without having to set everything up yourself.

## Why should you choose Modded OS?

- Preinstalled themes and a customized UI give you a ready-to-go experience. If you use it for work, the customized UI makes for an easy, smooth workflow.
- Everyday software such as a browser, GIMP, file managers, Visual Studio Code, a music player, Sticky Notes and LibreOffice comes included, along with preconfigured repositories and an up-to-date system.
- Optimized for better performance compared to a regular distro.
- A separate channel for Modded OS users on our Discord server.

Take a look at our [Modded OS Gallery](https://next.andronix.app/products/modded-os).

## How to install a Modded OS?

Andronix offers 4 Modded distributions to choose from.

Here's what you need to do before the distro is ready to use:

1. Download the Modded OS file.
2. Set up the user, locale, and other required settings.
3. Start the distro with `./andro*distro*.sh`.
4. Start the VNC server and connect to it using a VNC viewer.

For a detailed walkthrough, see [Installing Modded OS](/modded-os/modded-os-installation).
