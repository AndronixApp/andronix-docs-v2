Welcome! Andronix is an app that lets you install Linux distributions like Ubuntu, Debian and Manjaro on your Android device, no root required.

<Callout type="info">**Andronix 2.0:** free distros now install with one `andronix` command, with the latest versions (Debian 13, Ubuntu 26.04 LTS, Fedora 44 and more), a choice of XFCE, LXQt, MATE or KDE Plasma, and Firefox included. The install command in the app works as before. [See what's supported](/reference/distros).</Callout>

Pick one of the guides below to get started.

<Callout type="info">Get paid up to $100 to maintain a distribution for Andronix. Read more in [Calling for Maintainers](/blog/andronix-maintainers).</Callout>
