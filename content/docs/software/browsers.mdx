This page shows you how to install Firefox and Chromium in your Andronix distro. Find your distro under each browser and run the matching command.

<Callout type="warning">If you have an **armv7**-based device, browsers might fail to work for unknown reasons.</Callout>

<Callout type="info">These instructions assume that you have started your distro and are inside the distro shell (not the
Termux shell).</Callout>

## Firefox

Run the command for the distro you're using to install Firefox:

### Ubuntu 18/ Ubuntu 20/ Debian/ Kali Linux

```bash copy
apt install firefox-esr -y
```

### Arch / Manjaro

```bash copy
pacman -S firefox --noconfirm
```

### Void Linux

```bash copy
xbps-install -S firefox
```

### Alpine

Sadly, Alpine does not provide Firefox for ARM devices as of now.

## Chromium

Run the command for the distro you're using to install Chromium:

### Ubuntu / Ubuntu 19 / Debian / Kali Linux

```bash copy
wget https://raw.githubusercontent.com/AndronixApp/AndronixOrigin/master/Uninstall/ubchromiumfix.sh && bash ubchromiumfix.sh

```

<Callout type="info">If Chromium doesn't launch from the application menu, try one of the following commands in a terminal inside VNC:</Callout>

```bash copy
chromium --no-sandbox
```

```bash copy
chromium-browser --no-sandbox
```

### Arch / Manjaro

```bash copy
pacman -S chromium --noconfirm
```

### Void Linux

Sadly, Chromium is not available for Void Linux.

### Alpine

```bash copy
apk add chromium
```

### Fedora

```bash copy
dnf install chromium 
```
