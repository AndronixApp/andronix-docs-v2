We love to code, and Andronix turns your phone into a portable computer, so why not use it to code anywhere? You can run full-fledged IDEs inside Andronix. This page shows you how to set up IntelliJ IDEA and VS Code.

<Callout type="warning">We have only tested VS Code, IntelliJ IDEA, IntelliJ DataGrip, MonoDevelop (tested with GTKsharp, ASP.NET and
ASP.NET Core; the last has a problem with the target framework), Mono (in the console, you can compile simple console
programs in C#) and .NET Core. You can test other IDEs and edit this page to add them to the list.</Callout>

## IntelliJ IDEA

Here are the steps to install IntelliJ IDEA on your Andronix instance.

<Callout type="info">These instructions assume that you already have the SDK for your language installed in the distro you're
using.</Callout>

* Download the latest tar.gz file from the JetBrains
  official [download page](https://www.jetbrains.com/idea/download/#section=linux).
* Make sure the downloaded tar.gz is in your download folder, then run the following command.
  Replace the `x`s with the version in the name of the file you downloaded.

```bash copy
tar -xzf ideaIU-2xxx.x.x.tar.gz -C ~/Desktop/
```

* The archive should now be extracted to `Desktop/ideaIU-2xxx.x.x`, where the `x`s stand for the year and version number.
* Next, pick the command for your distro below and run it in the Linux terminal.

### Debian/ Ubuntu/ Kali Linux

```bash copy
sudo apt install openjdk-11-jdk -y
```

### Arch/Manjaro

```bash copy
sudo pacman -S jdk-openjdk
```

### Void Linux

```bash copy
xbps-install -S openjdk
```

### Alpine

```bash copy
apk --no-cache add openjdk11 --repository=http://dl-cdn.alpinelinux.org/alpine/edge/community
```

### Fedora

<Callout type="warning">
Fedora is not recommended for use with JetBrains IDEs.
</Callout>

* You can now run IDEA. Navigate to `Desktop/ideaIU-2xxx.x.x/bin` and run `idea.sh` with the following
  command:

```bash copy
./idea.sh
```

* Yay! 🎊 That's all you need to do to run IntelliJ IDEA on your device.

## VS Code

<Callout type="info">Andronix supports VS Code on all four of our supported CPU architectures: ARM64 (armv8), armv7,
i686 and x86_64.</Callout>

<Callout type="info">VS Code comes pre-installed with our [Modded OS](/modded-os/modded-os).</Callout>

### Debian based distros (Package Manager - apt)

Run the following command from within the distro's shell:

```bash copy
apt install wget -y && wget https://raw.githubusercontent.com/AndronixApp/AndronixOrigin/master/Uninstall/vscode_patch.sh && chmod +x vscode_patch.sh && ./vscode_patch.sh
```
