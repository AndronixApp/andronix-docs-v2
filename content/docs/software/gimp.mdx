GIMP is a free image editor that covers all your image editing needs. Follow the instructions below for your distro to install it.

<Callout type="warning">The following instructions assume that you're inside your distro's shell, not the Termux
shell.</Callout>

Find your distro below and run the commands in its shell:

### Ubuntu/ Debian based distributions

```bash copy
sudo apt-get update
sudo apt-get install gimp
```

### Arch Linux based distributions

```bash copy
sudo pacman -Syu
pacman -Syu gimp
```

### Fedora based distributions

```bash copy
sudo dnf update
sudo dnf install gimp
```
