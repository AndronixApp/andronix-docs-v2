XSDL is an X Window System (X11) server for Android. X11 servers are generally faster than VNC, but XSDL lacks the polished interface a VNC viewer might have. Which one you use comes down to your preference and what suits you best. This page shows how to start your distro's desktop with XSDL.

## How to start an XSDL server?

1. Download and install the XSDL app from the Play Store.
2. Open XSDL and wait until it finishes starting up.
3. Start your distro, then run this command inside the distro's shell to send its desktop to XSDL:

```bash copy
export DISPLAY=127.0.0.1:0 && bash ~/.vnc/xstartup &
```

If you're on a Wi-Fi network and want to access XSDL from other devices, use this command instead:

```bash copy
export DISPLAY=192.168.0.100:0 && bash ~/.vnc/xstartup &
```
