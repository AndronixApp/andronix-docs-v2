---

Andronix has a new installer for its free distros. If you installed a distro before it arrived, this page explains what happens to that install and how to move to the new one.

<Callout type="info">**Nothing changes for your existing install.** The new installer never modifies or deletes a distro installed by the old one, unless you ask it to.</Callout>

## How to tell which installer you used

Run this in Termux:

```bash copy
andronix list
```

Distros from the old installer are listed as **from the old installer**, with their folder, for example `~/debian-fs`. If the command isn't found, you haven't used the new installer yet, and everything you have is from the old one.

Other signs of an old install:

- It logs you in as `root` (`root@localhost`). New installs log you in as your own user.
- Its files are in a folder like `~/debian-fs` or `~/ubuntu-fs` in Termux. New installs live in `~/.andronix/distros/`.

## Outdated versions

The old installer set up versions that are now out of date. The new installer replaces them:

| Old install | New installer |
|---|---|
| Ubuntu 18.04, Ubuntu 20.04 | Ubuntu 24.04 LTS |
| Ubuntu 22.04 | Ubuntu 26.04 LTS |
| Older Debian, Kali, Fedora, Arch, Manjaro, Alpine and Void | The current versions, see [Supported Distros](/unmodded-distros/distros) |
| Window managers (Awesome, i3, Openbox) | Retired. Pick a [desktop environment](/desktop-environments/desktop-environments) instead. |
| LXDE and other desktops | XFCE, LXQt or MATE |

Your old install keeps working as it is, but it won't get these new versions.

## Installing the new version next to the old one

You can install the same distro with the new installer while you still have the old one. The new install goes into its own folder, and your old install is left alone.

- The new install uses the usual start script name, for example `start-debian.sh`.
- If you already had a start script with that name from the old installer, it's kept under a different name so you can still start your old install. Run `ls ~/start-*` in Termux to see your start scripts.

## Moving your files

The new install starts fresh. To bring files across:

1. In the old distro, copy what you want to keep to `/sdcard`, for example `cp -r ~/Projects /sdcard/`.
2. Install the new version from the app.
3. In the new distro, copy the files back from `/sdcard`.

Programs you installed in the old distro need to be installed again in the new one.

## Removing an old install

When you no longer need the old install, remove it from Termux:

```bash copy
andronix remove debian --legacy
```

Replace `debian` with the name of your distro. `--legacy` removes the old install's folder, its start script and its `~/<distro>-binds` folder. If the same distro is also installed with the new installer, that's removed too, so only use this when you want both gone.

You can also keep using the app's **Uninstall** button, as before. See [Uninstalling a Distro](/unmodded-distros/unmodded-os-uninstallation).
