Learn how to uninstall a Linux distro you installed with Andronix. The app generates the uninstall command for you, so all you need to do is run it in Termux. You can also remove a distro yourself with one command; see [Uninstalling from Termux](#uninstalling-from-termux).

<Callout type="info">These instructions need the **Andronix app 10.0 or newer (Andronix 2.0)**. Don't want to use the app? See [Uninstalling from Termux](#uninstalling-from-termux).</Callout>
<Callout type="info">This is **not** a guide for uninstalling a **Modded OS**.</Callout>
<Callout type="warning">Uninstalling deletes everything inside the distro. Copy anything you want to keep to `/sdcard` first, or make a backup with [`andronix backup`](/andronix-cli/andronix-cli#backing-up-and-restoring).</Callout>

## 1. Preparation 🚀

### Open Andronix app
Open the Andronix app and tap the **Linux Distribution** card on the dashboard.

<Imagera src="/images/install_new/install_dashboard.jpg"/>

### Select Distribution
You'll now see all the distributions available in Andronix.

<Imagera src="/images/install_new/install_distro_selection.jpg"/>

## 2. Selection ⭐

### Long Press on Distribution
**Long press** the distro you want to uninstall. This opens a menu with options for that distro.

<Imagera src="/images/uninstall_new/distro_uninstall_bottomsheet.jpg"/>

### Select Uninstall
Tap the **Uninstall** button to start the process.

## 3. Termux Execution 💻

This is where your Linux distribution actually gets removed.

<Callout type="info">The Andronix app has automatically copied an uninstall command to your clipboard.</Callout>

<Imagera src="/images/install_new/install_termux_exec.jpg"/>

### Termux
You'll run this command in Termux to remove the distro.

<Callout type="warning">Before you continue, make sure you're using a compatible version of Termux. If you haven't already, follow the [Migrating Termux to F-Droid](/termux/migrating-to-f-droid) guide.</Callout>

### Paste and Execute
First, stop the desktop (`vncserver-stop`) and `exit` the distro if it's running. Then, in Termux, **long press to paste the copied command, then press Enter to run it**.

<Imagera src="/images/uninstall_new/distro_uninstall_termux_exec.jpg"/>

### All done!
That's it! You've successfully uninstalled the Linux distribution from your Android device.

## Uninstalling from Termux

If you installed the distro with Andronix 2.0, you can remove it without the app. Stop the desktop and `exit` the distro, then run this in Termux:

```bash copy
andronix remove debian
```

Replace `debian` with the name of your distro (`ubuntu`, `ubuntu24`, `kali`, `fedora`, `arch`, `manjaro`, `alpine` or `void`). Run `andronix list` if you're not sure what's installed.

The command shows what it will delete and asks you to confirm. It removes the distro and its start script. Your files in `/sdcard` are not touched.

<Callout type="info">To also remove a copy of the same distro installed by the pre-2.0 installer, add `--legacy`, for example `andronix remove debian --legacy`. See [Installs from before Andronix 2.0](/unmodded-distros/older-installs).</Callout>
