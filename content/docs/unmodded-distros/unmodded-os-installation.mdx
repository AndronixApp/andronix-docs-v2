Installing your favorite Linux distro with Andronix only takes a few minutes. This guide walks you through the whole process: picking a distro, choosing an interface, running the install command in Termux, creating your user, and starting your new system. Prefer video? Watch the walkthrough below, then follow the steps.

<Callout type="info">These instructions need the **Andronix app 10.0 or newer (Andronix 2.0)**. Don't want to use the app? See [Installing without the app](#installing-without-the-app).</Callout>
<Callout type="info">This is **not** a guide for installing a **Modded OS**. For that, see [Installing Modded OS](/modded-os/modded-os-installation).</Callout>

## 1. Preparation 🚀

### Linux Distributions
Open the Andronix app and tap the **Linux Distribution** card on the dashboard. This takes you to the list of distros you can install.

<Imagera src="/images/install_new/install_dashboard.jpg"/>

### Selection
You'll now see every distribution that can be installed on your Android device.

<Imagera src="/images/install_new/install_distro_selection.jpg"/>

## 2. UI Selection ⭐️

### Select
Tap the distro you'd like to install.

<Callout type="warning">Not sure which one to pick? We recommend starting with **Ubuntu**.</Callout>

### Select the UI
Next, choose the kind of interface you want. This decides how you'll interact with your distro once it's running.

<Imagera src="/images/install_new/install_gui_selection.jpg"/>

<Callout type="info">A Graphical User Interface (GUI) is the visual interface, with windows, icons and a mouse pointer, that you use to get things done in your Linux distribution.</Callout>

<Callout type="info">A Command Line Interface (CLI) is the text-based interface where you type commands to perform tasks in your Linux distribution.</Callout>

#### **Desktop Environment** <Badge>GUI</Badge>
Choose a Desktop Environment if you want to use your mouse as well as your keyboard, or if you have little or no experience with Linux. [Learn more about Desktop Environments](/desktop-environments/desktop-environments).

#### **Command Line Interface** <Badge>CLI</Badge>
Choose the **Command Line Interface** if you don't need a graphical interface. You'll get a terminal, which is all you need if you know your way around Linux. You can add a desktop later with [`andronix install`](/andronix-cli/andronix-cli#installing).

<Callout type="warning">**Window managers have been retired.** Andronix 2.0 offers desktop environments (XFCE, LXQt, MATE, and KDE Plasma on some distros) and the command line only. If your version of the app still shows a Window Manager option, pick a Desktop Environment instead. [Read more](/window-managers/window-managers).</Callout>

<Callout type="info">If you can't decide, we always recommend going with a Desktop Environment.</Callout>

### Continue
Follow the instructions below that match the option you picked.

#### Desktop Environment

Select the Desktop Environment (DE) you'd like to install: **XFCE**, **LXQt**, **MATE**, or **KDE Plasma** (Debian, Ubuntu 26.04 and Kali only). If you want to compare them first, read the [Desktop Environments](/desktop-environments/desktop-environments) page. If you're not sure, pick **XFCE**.

<Imagera src="/images/install_new/install_de_selection.jpg"/>

#### CLI

No extra configuration is needed for the Command Line Interface. Continue to the next section.

## 3. Termux Execution 💻

This is where the actual installation of your Linux distribution happens.

<Callout type="info">The Andronix app has automatically copied an install command to your clipboard.</Callout>

<Imagera src="/images/install_new/install_termux_exec.jpg"/>

### Execute
You'll run this command in Termux to download and set up the distro.

<Callout type="warning">Before you continue, make sure you're using a compatible version of Termux. If you haven't already, follow the [Migrating Termux to F-Droid](/termux/migrating-to-f-droid) guide.</Callout>

### Paste
Open the Termux app, **long press to paste the copied command, then press Enter to run it**.

<Imagera src="/images/termux_pkg_up.png"/>

### Wait
The command sets up the `andronix` installer and runs it. You'll see a list of steps, each ticked off with a ✓ as it finishes, with a progress bar for the long ones:

```text
✓ Checking your phone
✓ Finding the best download
✓ Downloading Debian 13
✓ Unpacking files
✓ Setting up Debian 13
✓ Refreshing package lists
✓ Updating Debian 13
✓ Installing XFCE desktop · 250 packages
✓ Installing Firefox
✓ Setting up the desktop
✓ Writing start-debian.sh
```

A desktop install usually takes a few minutes, depending on your phone and connection. Keep Termux open until it finishes.

<Callout type="warning">Android may ask whether Termux can keep running in the background. Tap **Allow**, and disable battery optimization for Termux, so Android doesn't stop the install.</Callout>
<Callout type="info">If the install stops for any reason, paste and run the **same command** again. It continues where it left off. See [Troubleshooting installs](/troubleshoot/install-problems) if it keeps failing.</Callout>

### Create your user
When the install finishes, it asks you to set up your user:

1. **Username**: lower-case letters and numbers, for example `alex`.
2. **Password**: used to log in and for `sudo`.
3. **Desktop (VNC) password**: 6 to 8 characters. If your password is 6 to 8 characters long, you can reuse it.

<Callout type="info">Free distros no longer log you in as `root`. Your user can run any command as root with `sudo`, for example `sudo apt install nano`. On Manjaro, where `sudo` doesn't work yet, use `andronix start manjaro --root` from Termux instead.</Callout>

When it's done, the installer takes you straight into your new distro.

### Update the Andronix app
Back in Andronix, tap the **Command Executed** button at the bottom of the screen. This tells the app the command has been run.

### Finish the Process
Once the script has finished successfully, tap the **Execution Finished** button at the bottom.

<Imagera src="/images/install_new/install_script_exec.jpg"/>

## 4. Starting Distribution ⚡️

<Callout type="info">If you're already in the distro shell (you see your username, like `alex@localhost`, in Termux), **skip the next section.**</Callout>

### Start the Distro
Next time, start the distro by running the command for your distro in Termux:

| Distro | Command |
|---|---|
| Debian 13 | `./start-debian.sh` |
| Ubuntu 26.04 LTS (the app's **Ubuntu 22** button) | `./start-ubuntu26.sh` or `./start-ubuntu22.sh` |
| Ubuntu 24.04 LTS (the app's **Ubuntu 18** and **Ubuntu 20** buttons) | `./start-ubuntu.sh` or `./start-ubuntu20.sh` |
| Kali Linux | `./start-kali.sh` |
| Fedora 44 | `./start-fedora.sh` |
| Arch Linux | `./start-arch.sh` |
| Manjaro ARM | `./start-manjaro.sh` |
| Alpine 3.24 | `./start-alpine.sh` |
| Void Linux | `./start-void.sh` |

You can also use `andronix start <distro>`, for example `andronix start debian`. See [Supported Distros](/unmodded-distros/distros) for details on each one.

### Verify
If you see your username followed by `@localhost` in the shell, your distro is up and running. Type `exit` to go back to Termux.

## 5. VNC Configuration 📺

If you chose a Desktop Environment, you'll use VNC to see and use it.

### VNC Start

The **Start VNC server** page should now be open in the Andronix app.

<Imagera src="/images/install_new/install_start_vnc.jpg" />

### VNC Server

Inside the distro, start the desktop:

```bash copy
vncserver-start
```

Press **Enter** to pick the Auto screen size. Then open a VNC viewer app and connect to `localhost:1` with your desktop password. Follow the [VNC Basics](/vnc/vnc-basics) guide for the full walkthrough.

<Callout type="warning">Keep the Termux session open while you use the desktop. Closing it, or typing `exit`, stops the desktop too.</Callout>

![Debian 13 with XFCE, seen in a VNC viewer](/images/new-installer/debian-xfce-desktop.png)

<Callout type="error">Seeing the **Process completed (signal 9) - press Enter** error in Termux? Read [Android 12 and Newer](/android-12/andronix-on-android-12-and-beyond) to fix it.</Callout>

## Installing without the app

You can install any free distro straight from Termux, without the Andronix app. Paste this one line into Termux, replacing `debian` and `xfce` with the distro and desktop you want:

```bash copy
curl -fsSL https://dl.andronix.app/get.sh -o $PREFIX/tmp/get.sh && sh $PREFIX/tmp/get.sh install debian --de xfce
```

It downloads the `andronix` command, checks it, and starts the install. The rest is the same as above: the install steps, [creating your user](#create-your-user), and [starting the distro](#start-the-distro).

- **Distro names:** `debian`, `ubuntu` (26.04), `ubuntu24`, `kali`, `fedora`, `arch`, `manjaro`, `alpine`, `void`. See [Supported Distros](/unmodded-distros/distros).
- **Desktops:** `xfce`, `lxqt`, `mate`, `kde` (Debian, Ubuntu 26.04 and Kali only) or `none` for the command line only.

{/* TODO(docs): remove this proot step once x11's final gate confirms installer 2.0.0 installs proot itself (feat-proot-install, step 'Installing proot'). */}

<Callout type="info">On a fresh Termux, install `proot` first with `pkg install proot -y`. If it's missing, the installer stops and tells you to.</Callout>

Once `andronix` is installed, you can install more distros with just `andronix install <distro> --de <desktop>`.
