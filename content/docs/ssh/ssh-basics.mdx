SSH lets you access your device's shell remotely. This page covers two ways to run an SSH server: from Termux and from inside your Linux distro.

We recommend running the SSH server from Termux rather than from the Linux environment. An SSH server running in Termux gives you control of both your device and your Linux OS. Both methods are described below.

## SSH via Termux

Follow [this guide](https://glow.li/technology/2015/11/06/run-an-ssh-server-on-your-android-with-termux/) to learn how
to run an SSH server from Termux. The tutorial is officially provided by one of the Termux developers.

## SSH via Linux

Since Linux runs through PRoot, it cannot override Android's default connectivity configuration, so the SSH port
number needs to be changed. Follow the steps below to run SSH from Linux:

<Steps>
<Step>

### Install OpenSSH

Install **OpenSSH** inside Linux. Pick the command for your distro from the list below:

#### Ubuntu 20

```bash copy
apt install openssh-server nano -y
```

#### Ubuntu 18

```bash copy
apt install openssh-server nano -y
```

#### Kali Linux

```bash copy
apt install openssh-server nano -y
```

#### Debian

```bash copy
apt install openssh-server nano -y
```

#### Manjaro

```bash copy
pacman -S openssh nano --noconfirm
```

#### Arch

```bash copy
pacman -S openssh nano --noconfirm
```

#### Fedora

```bash copy
dnf install -y openssh-server nano
```

#### Alpine

```bash copy
apk add openssh-server nano
```

#### Void

```bash copy
xbps-install openssh nano
```

</Step>

<Step>

### Modifications

Once the OpenSSH server is installed, you need to change a few settings so it's reachable over the network despite Android's limitations. Open the SSH config file:

```
nano /etc/ssh/sshd_config
```

* Find the line `#Port 22` and change it to `Port 2222`.
* Find the line `#PermitRootLogin prohibit-password` or `#PermitRootLogin yes` and change it to `PermitRootLogin yes`.
  If it already says `PermitRootLogin yes`, you don't need to change anything.
* When you're done, press `CTRL+X`, type `Y` and press `Enter` to save.

</Step>

<Step>

### Generate Keys

Next, generate the host keys by running:

```bash copy
ssh-keygen -A
```

and then:

```bash copy
ssh-keygen
```

</Step>

<Step>

### Password

Now set a password for the root user by running:

```bash copy
passwd
```

Enter any password you like.

</Step>

<Step>

### Start SSH Server

Once that's done, start the SSH server by running:

```bash copy
/usr/sbin/sshd
```

</Step>

<Step>

### Connect

Run the following command:

```bash copy
ip a
```

and copy the IP address listed under `wlan`. To connect to the SSH server, run:

```bash copy
ssh root@localhost -p 2222
```

and log in with the password you set earlier.

</Step>
</Steps>
