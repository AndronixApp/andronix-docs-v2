<Callout type="warning" title="Window managers have been retired">
The new Andronix installer no longer offers window managers (Awesome, i3 and Openbox). New installs come with a [desktop environment](/desktop-environments/desktop-environments) (XFCE, LXQt or MATE) or the command line only. If your version of the app still shows a Window Manager option, pick a desktop environment instead.

Distros you already installed with a window manager keep working. This page is kept for them. See [Installs from the old installer](/unmodded-distros/older-installs).
</Callout>

This page explains what a window manager (WM) is and which WMs the old installer offered for each distro.

According to the [Wikipedia article](https://en.wikipedia.org/wiki/Window_manager) on window managers:

> A window manager is system software that controls the placement and appearance of windows within a windowing system in a graphical user interface. Most window managers are designed to help provide a desktop environment. They work in conjunction with the underlying graphical system that provides required functionality—support for graphics hardware, pointing devices, and a keyboard, and are often written and created using a widget toolkit.

In simpler terms, a **window manager is a program that places, removes and generally manages your windows**.

## What should I use instead?

Pick a [desktop environment](/desktop-environments/desktop-environments). **XFCE** is our recommendation. If you liked a window manager for its light weight, try **LXQt**.

You can still install a window manager yourself inside a distro with its package manager, for example `sudo apt install i3` on Debian, but Andronix doesn't set it up or support it.
